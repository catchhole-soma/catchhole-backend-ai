# 조건부 위험과 실제 상태의 구분

기존 `semantic_safety`를 보존하고 만든 별도의 5화 안전성 fixture다. 원래의 카엘 오른발 부상·왼팔 상처·저주, 미라 오른발 부상 및 4화 회복·5화 회고 흐름을 유지한다.

- 2화의 카엘 감염은 상처를 방치했을 때 앞으로 생길 수 있다는 조건부 위험이다. 현재 감염이 발생한 관찰이 아니다.
- 3화에는 미라의 오른발 상처에 실제 감염이 새로 발생한다. 4~5화에서도 감염이 지속된다. 같은 감염 어휘를 조건문이라는 이유로 일괄 제외해서는 안 된다.
- 3화의 카엘은 약이 들면 통증이 사라질 것이라고 기대하지만, 실제로는 부축받아 두 걸음만 옮기며 붓기·통증이 그대로다. 기존 오른발 부상 종료 시점은 여전히 4화다.
- 카엘의 회복은 미라의 오른발 부상·감염이나 카엘의 왼팔 상처·저주를 제거하는 근거가 아니다.

`expectations.json`은 사후 사람 검수 전용이다. 모델에는 txt 원문만 정상 분석 경로로 전달하며, 이 README와 기대값을 prompt에 넣지 않는다. 이름·key 철자를 코드에서 정답으로 강제하지 않는다.

`expectedInactive`는 회차 확정 후 현재 상태에 없어야 한다는 뜻이다. 과거에 실제 발생했다가 종료됐다는 뜻은 아니다. 따라서 카엘 감염의 부재를 REMOVE 성공으로 채점하지 않는다. 미라 감염은 3화에 최초 확립됐는지부터 확인하고 3~5화 보존을 판정한다.

이 fixture의 결과는 기존 `semantic_safety` 및 본문 반복 검증과 구분해 기록한다.
