# 상태 종료 관찰 검증 원고

기존 semantic_safety_temporal의 발·팔·저주·감염 대조군을 유지하고, 기억·발성·환경 시야의 후속 기능 회복과 단발성 처치/실제 지속 효과를 추가했다. 기대값은 사후 독립 검수에만 사용하고 모델에는 회차 txt만 제공한다. 특정 작품의 인물이나 원문 문장을 복사하지 않았다.

## 추가 근거 함의 경계

카엘의 오른쪽 청력 저하가 2화에 발생한다. 3화의 큰 소리가 회복 때문인지 상대 음량 때문인지 불분명하며, 4화의 운동·시각 행동과 정상 왼쪽 청각으로 오른쪽 청력을 종료하면 안 된다. 5화까지 원래 귀 상태를 보존한다. 이 기대값 문서는 모델 입력이 아니며 runner는 txt 원문만 전송한다.
