# v0028 — 독립 관계 호출과 회차별 관계도

2026-10-29 · [상세 근거](details/v0028.md) · [Java #323](https://github.com/catchhole-soma/catchhole-backend-java/issues/323)

캐릭터·세계관 추출을 유지하고 관계만 Terra/medium의 독립 1·2차 호출로 처리한다.
1차는 원문 조각 ID를 골라 인용 복사 오류를 줄이고, 2차는 기존 관계와 새 관찰을 비교한다.
관계 추가·변경·종료는 회차 이력에 남기고 애매한 관찰은 사용자 검토함 없이 내부 보류한다.

| 검증 | 결과 |
|---|---|
| 전체 pytest | 4,786 passed / 140 skipped / 기존 경고 1 |
| Ruff / diff 검사 | 변경한 관계 코드·테스트·CLI 통과 |
| 실제 1~4화 관계 추출 | 4호출, 18관찰 중 원문 검증 18수락·0탈락 |
| 실제 관계 비교 | 4호출, 최종 활성 관계 2개·보류 13관찰·제외 3관찰 |
| 호출/구조 오류 | 0 / 8호출 |
| 캐릭터·세계관 Gold / 관계 F1 | 미측정 |

비교 실험의 인물 연결은 합성 exact-name mapping이다. 실제 Java DB 통합의 품질 점수가 아니다.
원문과 모든 결과를 수동 대조해 근거 없는 친구·연인·쌍방 감정 생성은 찾지 못했다.
두 사람의 태도 차이는 방향별 관계로 보존됐다. 위치 검증 통과를 의미 정확도로 해석하지 않는다.

이름 없는 화자·역할이 포함된 13관찰은 안전하게 인물을 연결할 근거가 없어 보류됐다.
회상 1건의 시점 오분류와 3관찰의 인용 문맥 부족도 남았다. 친구·연인 긍정 평가 사례는 부족하다.
실제 비교에 기존 관계가 없어 변경·종료는 실모델로 검증하지 못했고 자동 회귀로 확인했다.
보류가 나중에 모두 자동 해결된다고 보장하지 않으며 화자/역할 해소와 후속 회차 검증이 필요하다.

관계 출력 실패와 핵심 설정 실패를 구분하고 lease·권한·원문·quota 검증은 유지한다.
저장한 비교 입력/완료 결과로 재개하며, 기존 설정집·가계도 경로는 유지한다.
기존 회차 자동 백필과 무효화 후 자동 유료 재분석은 포함하지 않았다.
이번 버전은 로컬 구현·검증 상태이며 PR·운영 배포는 아직 수행하지 않았다.
