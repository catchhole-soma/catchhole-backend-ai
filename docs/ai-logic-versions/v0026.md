# v0026 — 고정 자료로 설정 충돌 질문·근거·판정

2026-10-28 · [Java #306](https://github.com/catchhole-soma/catchhole-backend-java/issues/306)

신규 원고를 기존 설정과 비교하기 전에 질문·누락 보완·실제 조회·근거 판정을 분리한다.
검수 준비 때문에 설정 추출 Job이나 후보/현재값을 만들지 않는다.

- 저장한 기준과 실제 원문 revision만 읽고 다른 작품·후속 회차·교체/파기 자료를 제외한다.
- 같은 Terra의 medium/high/medium 역할에서 전체 구간과 조회 의무를 보존한다.
- 실패와 의미 모호성을 구분하고 DB↔원문 기준 불확실성은 양쪽 근거로 남긴다.

합성 hand-use/prosthetic 사례는 연결 회귀이며 실제 Terra 품질 평가가 아니다.
기존 추출·챗봇의 기본 모델/추론은 유지했다.
원문/근거/형식/예산 실패는 미완료이며 정상 0건으로 합산하지 않는다.
미분석 설정집의 실제 본문을 독립 보완에 제공하며 실제 검색 시간·조회 예산과 부분 벡터 준비 상태도 검증한다.
