# v0023 — 현재 설정 근거·후속 정정·원문 탐색

2026-10-22~26 · 작업 브랜치 · 운영 미배포 · 의미 품질 부분 완료

## 무엇을 바꿨나

- 현재 등록값과 원문을 구분하고 재검색에서도 인용 위치를 검증한 근거를 보존한다.
- 없는/중복 인용의 문장만 제외하고, 함께 제거된 요구를 완료로 처리하지 않는다.
- 추가 답변의 시간/출력 한도에 도달하면 앞선 부분 답변을 최종 재검증한다.
- 계획2,000·답변4,500·복구 최대6,000토큰,120초 내 최종 검증 여유10초를 둔다.
- 새 벡터 후보를 미확인 옛 키워드 후보보다 먼저 읽고, 기존 전체 예산은 유지한다.
- 최초 자동 테스트238실패를 cold tokenizer cache로 재현하고 시작 단계에서 준비한다.
- 리뷰 보완: 시간이 부족해도 재검증한 현재값은 보존하고, 미검증 원문 근거는 붙이지 않는다.
