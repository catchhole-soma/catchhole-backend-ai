# v0005 — 회차별 자동 확정과 연속 분석

2026-09-13 · 적용: [AI #70](https://github.com/catchhole-soma/catchhole-backend-ai/pull/70) · 이전: [v0004](v0004.md)

## 무엇을 바꿨나

- 앞 회차의 정상 설정을 저장한 뒤 다음 회차가 최신 확정 설정과 미해결 참고를 구분해 읽는다.
- 개별 후보의 연결·비교 실패는 원문과 이유를 보존해 직접 검토로 남기며 다른 후보와 다음 회차를 계속 처리한다.
- 제한된 재시도·부분 복구와 일반 불확실성 검토를 제공한다. 사용량·계정·고정 입력·lease·저장 오류는 계속 중단한다.

main의 신규 캐릭터 그룹 비교와 세계관 추출 기준(#69·#65)을 포함한다.
기존 모드는 입력 종료 후 그룹 비교를, 누적 모드는 회차별 비교·저장을 수행한다.

## 검증과 한계

**정답지 기반 정확도·재현율은 미측정이다.** 합성 회귀 결과를 품질 개선 점수로 해석하지 않는다.

| 확인 | 결과 |
| --- | --- |
| 오프라인 pytest | 1,883 통과 · integration 14개 제외 |
| 실제 PostgreSQL 저장 경계 | 12개 통과 |
| 실제 Spring HTTP ↔ Python Worker | 9개 통과 |
| 기존 모드 요청 6종 | main의 입력·모델·추론·응답 형식·출력 상한 유지 |

합성 원문과 고정 응답을 사용했으며 외부 LLM·judge는 호출하지 않았다.
기존 실제 20+10회차 기록은 당시 코드의 결과이고, 이번 통합 코드의 실측은 아니다.
주체 과병합·과도한 검토 보류와 실제 provider 품질은 추가 확인이 필요하다.
GH180 담당은 다음 승인된 실제 연속 실행을, 정확도 담당은 동일 Gold·모델·judge의 FIXED 평가를 진행한다.
