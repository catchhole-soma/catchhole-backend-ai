# v0027 — 독립 오탈자 검사

2026-10-29 최신 main 통합 · [상세 실행 근거](details/v0027.md) · [구현 PR #100](https://github.com/catchhole-soma/catchhole-backend-ai/pull/100)

설정 질문이 없거나 설정 검사가 실패해도 같은 고정 원고 전체를 독립 검사한다.
원문 위치·짧은 교정안·이유·맞춤법/띄어쓰기/명백한 오타 분류를 반환한다.
고유명사 표기·방언·의도한 말투·윤문은 제외하며 원고를 자동으로 수정하지 않는다.

한 구간 응답을 모두 검증한 뒤 성공 결과만 합친다.
독립 구간의 실패는 다른 성공 제안을 보존한 미완료 결과다.
원고 변경·파기 또는 최종 재검증 실패는 이전 제안을 모두 무효화한다.

| 검증 | 결과 |
| --- | --- |
| 오탈자·설정검수·공통·metering·선택 PG 집중 회귀 | 132 passed / 6 skipped / 0 warnings (오탈자 59개 포함) |
| 전체 pytest | 4,608 passed / 140 skipped / 기존 경고 1, 실패 0 |
| ruff | 신규 파일 통과, 전체 main 기존 480건과 증감 0 |
| wheel | 격리 build 성공, checker·prompt 원본 바이트 일치 |
| 실제 Terra 기본 예시 | R1 전 합성 3사례 완료: 기본 3제안·표기 대조 0·반복 2위치 |
| 추출 Gold / judge / 운영 원고 | 미측정 |

모델은 선택된 `gpt-6.1-terra`, 호출별 추론 `low`다.
기존 추출·챗봇의 기본 모델과 추론 설정은 유지한다.
R1은 숨은 계량 재시도를 거절하며 raw 또는 재시도 0인 단층 wrapper만 허용한다.
구조 검증 통과를 실제 모델의 의미 정확도나 전체 원고 무누락의 증거로 집계하지 않는다.
운영 품질 합격선이나 모델 비교 결과는 추가하지 않았다.
