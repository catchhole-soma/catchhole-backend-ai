# v0024 — 동일 원문 재분석의 청크 참조 보존

2026-10-27 · 적용: 작업 브랜치, main 미반영·운영 미적용

## 무엇을 바꿨나

- 같은 원문과 같은 분할 경계로 다시 분석하면 기존 청크 ID·임베딩을 보존한다.
- 본문·순서·offset·문단 경계가 다르면 기존 교체를 유지한다.
- 확정값·이력이 참조하던 청크 ID가 새 분석 때문에 끊겨 후속 분석을 막는 원인을 제거한다.
