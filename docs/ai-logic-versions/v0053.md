# v0053 — 설정집 인물 입력 축소와 실제 모델 검증

2026-11-09 · [이슈 #147](https://github.com/catchhole-soma/catchhole-backend-ai/issues/147) · Draft 검토 / 미배포

## 무엇을 바꿨나

설정집에 반복되던 이름·별칭·인물 근거·동일 STATUS를 한 번씩 전달한다.
전체 인물 목록은 남기고 `이름: level=12` 같은 수치 표만 상세를 선택한다.
일반 서술·간접 지칭은 전체 상세를 보존한다. 원문에 다시 나온 현재 사실과
표의 명시적 수식어도 추출하도록 보완했다. 64,000 한도와 후속 처리는 유지한다.

**특정 기관명을 상위 조직으로 표현한 2건이 남아 있어 품질 무저하를 선언하지 않는다.**
Draft PR에 세부 보존 회귀로 명시하며, 원문 정답을 사후 완화하지 않았다.

실제 모델은 Terra6.1·medium, 같은 재구성 입력으로 비교했다. 기존 버전은 평가에서만
애플리케이션 한도를 우회했다. 이 표는 원문 사실 보존 감사이며 정규 다단계 F1이 아니다.
7건의 실측 입력은 402,834→338,693토큰, 출력은 33,932→55,482토큰이다.
출력 사실이 늘어 지연도 늘었으므로 비용·속도 개선으로 단정하지 않는다.

전체 테스트 5,760통과 / 186skip. 운영 상태·사용자 차감·배포는 변경하지 않았다.
후속 인물 해소·비교·최종 저장은 미측정이며 간접 주체의 정확한 기존 상태 연결도 남은 범위다.
