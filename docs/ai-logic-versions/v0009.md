## 무엇을 바꿨나

- 질문에서 등록 정보 필요와 장면·이유·과정 필요를 독립적으로 구분한다. 단순 RDB 답변은 기존 추출형 경로를 유지한다.
- 직접 근거가 부족하면 키워드·인접 원문, 이어서 벡터 검색으로 확대한다. 전체 허용 범위에서 조회하고 겹침·회차 편중·문맥량을 제한한다.
- 주장별 근거를 연결하고 Spring이 실제 현재 원문과 인용 receipt를 다시 검증한다. 원문 변경 시 답변을 보류한다.
- PR 리뷰에서 모델 호출 설정을 1~6회로 고정하고 CI 테스트 전 토크나이저 준비를 추가했다.
- 추가 리뷰에서 실패 정산·RDB 누락 안내·인접/벡터 검색 중복을 보완하고, 부분 답변과 근거를 보존해 재검증 후 복구한다.
