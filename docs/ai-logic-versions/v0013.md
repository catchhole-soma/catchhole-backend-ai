사용자가 로컬 테스트 불필요를 명시하고 앞선 API 테스트 요청을 취소했다.

평가의 6,000/9,000 최초 override와 과거 실행 결과는 보존한다.
현재 평가 절단 재시도는 runtime의 기본 64,000을 따른다.
코드·배포 설정을 커밋해 PR 브랜치에 push했다. 머지·배포·서버 재시작은 수행하지 않았다.
