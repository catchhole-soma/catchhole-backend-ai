# v0048 — 챗봇 모델 주도 원문 탐색·사실 추출 두 단계 답변 (#319 4차, 기본 꺼짐)

2026-11-06 · 적용: 작업 브랜치 `feat/gh-319-chat-agent-retrieval` · [Java #319](https://github.com/catchhole-soma/catchhole-backend-java/issues/319)

## 무엇을 바꿨나

- 원문 질문의 틀린 답 상당수가 "정답 근거가 모델 입력에 없거나 일부만 있음"이었다. 고정 순서(키워드 1회 → 벡터 최대 2회, 조각 12개)를 대신해, 모델이 읽은 원문을 보고 다음 검색어·통째로 읽을 회차·검색 정렬을 고르는 탐색 단계를 반복하고 읽은 조각을 한 묶음에 쌓는 경로를 추가했다(`CHAT_RETRIEVAL_AGENT`, 기본 `false`).
- 답변을 두 단계로 나눴다. 읽은 묶음을 회차 순 묶음으로 나눠 병렬로 사실과 인용문을 뽑고, 서버가 인용문을 원문과 글자 그대로 대조한 뒤 검증된 사실만으로 답을 쓴다. 빈 답이면 같은 원문을 한 번의 답변 호출로 다시 읽힌다.
- 회차 통째 읽기와 검색어별 회차 분포 조회를 더했고, 검색 인용 상한을 12개에서 60개로 넓혔다. 본문 상한 초과(413)는 다시 보내지 않는 실행 한도 실패로 처리한다.

스위치가 꺼져 있으면 계획·검색 라운드·답변 요청·검증은 v0044와 같다. 기존 프롬프트(plan v14, answer v16)와 기존 설정의 기본값은 바꾸지 않았다. 실험 사본에 있던 회차 요약 색인은 효과를 확인하지 못해 옮기지 않았다.
