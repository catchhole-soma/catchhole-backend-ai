# v0055 — 검수 중 일시적인 AI 호출 오류 복구

## 변경 이유
5개 검수를 동시에 실행했을 때 4개가 일부 미완료로 끝났다.
의도한 오류는 찾았지만, 396개 질문 중 5개는 호출 실패로 판단하지 못했다.
기존 기록에는 HTTP 상태가 없어 일시 장애인지 요청 문제인지 구분하기 어려웠다.

## 바뀐 내용
- 실패한 호출의 상태 코드와 안전한 요청 식별자를 기록한다.
- 속도 제한·일시 서버/통신 오류만 최초 포함 최대 3번 시도한다.
- 서버의 대기 지시와 기존 실행·사용량 한도를 지킨다.
- 실패한 호출도 사용량 불명으로 보존하고 새 시도는 별도 예약한다.
- 설정 검수와 오탈자 검사에 적용하며 프롬프트와 모델은 유지한다.

## 남은 확인
오프라인 테스트는 재시도·취소·예산·사용량 보존을 확인한 결과다.
새 코드 배포 뒤 같은 원고 5개를 동시에 검수해 완료율과 시간·오탐을 다시 확인한다.
입력 오류·권한·결제 한도는 재시도하지 않으며 의미 오탐은 별도 문제로 남는다.
