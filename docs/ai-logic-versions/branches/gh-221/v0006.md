# v0006 — 설정집 공통 분석·기준시점과 현재값 보호

2026-10-06 / 10-08 · 적용: 작업 브랜치 · 이전: [v0005](v0005.md)

## 무엇을 바꿨나

- 실제 설정집 리비전을 출처로 인물·세계관을 함께 추출·비교한다. 원문·청크·후보를 고정하고 중단 후 같은 ID로 재개한다.
- 작품 시작·특정 회차 종료·미지정 기준을 고정 입력으로 전달한다. 책과 회차 양방향 비교에서 이전·같은·불명확한 시점의 충돌과 작가 수정·삭제는 검토로 남긴다.
- 제목과 항목의 문맥을 보존하고, 동명이인은 근거별 앵커로 유지한다. 미래·가정·불명확한 주장도 삭제하지 않고 검토 후보로 보존한다.
- 새 ordered 추출은 고정 CURRENT 구조를 읽고 같은 의미축의 key·분류를 고려한다. 현재 문맥을 원문 근거로 쓰거나 시간·범위·작가 보호를 우회하지 않는다.
- 실제 현재 STATUS와 아직 실현되지 않은 회복·악화 전망은 별도 후보로 보존하고 전망을 기존 시간 검토로 남기도록 안내한다.

## 검증과 한계

**실제 Round4 A01은 72/72 field PASS, C01은 56/56 field PASS다. A02는 제품 계약 31/32 충족·전체 FAIL, C02는 28/32 충족·전체 FAIL이다.** A02의 전망 검토 누락과 C02의 과거·일시 정보 현재 유입은 별도 결함이다. 분모가 다른 이 결과를 F1·개선율로 세지 않는다.

기준시점 구현 당시 전체 회귀는 격리 PG 23건·실제 Java 계약을 포함한 **2,108 통과 · 0 제외 · 기존 경고 1개**였다. 인물 EXCLUDE의 기준 상충도 검토로 보존하며 회차 golden/parity는 유지한다.
AI는 서버가 보류할 값을 임시 현재 상태에도 미리 적용하지 않는다. 서버의 버전·출처·작가 보호 검증은 별도 필수 경계다.
BOOK 세계관은 원문 연속 인용과 독립 제목을 확인하고, 내부 미확인 표식이 없거나 불명확하면 현재값·동일 주체 근거로 승격하지 않는다. 정상 기능은 종료할 이상 상태와 구분해 양의 현재 정보로 추출하도록 안내한다.
v5의 실제 PG/socket 포함 전체 2,373개와 독립 구현 검사 131개가 통과했다. 최신 v6 오프라인은 **2,368 통과 · 0 실패 · DB 23개와 지표 포트 2개 별도 대기**다. 원문·Gold와 기존 HTTP golden/parity는 수정하지 않았다.
부모 밖 설정은 규칙 별칭 선택까지 ID·증명 없이 정상 연결 대기로 격리해 프로필 전체 실패를 막는다. 전체 partition과 discovery 검증은 유지한다.
일회 사건을 영구 관계로 요구한 oracle 오류는 별도 판정하며 원래 Gold/FAIL을 보존한다. 사건 추출 도메인은 확장하지 않는다.
v6 신규 경로 20개는 현재/전망의 양방향 순서·근거·재시도와 현재 권한 분리를 확인했다. C02 수정은 포함하지 않았다. 전체 PG/socket·독립 재검토·새 실제 분석이 남았으며 다음 단계는 BLOCKED다. 합성 응답 통과를 의미 성공으로 세지 않는다.

## 이전 실제 연결 검증

기준시점 보완 전 55자 책 1건을 실제 Sol·medium으로 분석했다. `SUCCEEDED + SEALED`로 인물 1명/설정 2개와 세계관 1개를 자동 반영했다. 이 작은 연결 확인은 최신 정책 검증이나 F1 평가를 대체하지 않는다.
공급자의 64자 `prompt_cache_key` 제한은 짧은 키를 유지하고 긴 논리 키만 전체 UTF-8 SHA-256을 담은 64자 키로 변환했다. 이 수정은 그대로 유지한다.
