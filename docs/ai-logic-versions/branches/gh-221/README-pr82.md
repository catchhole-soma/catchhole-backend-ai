## 기록 위치

- **사람이 읽는 요약:** `vNNNN.md` — 변경 내용 3줄 안팎, 점수 표, 남은 문제. [요약 템플릿](TEMPLATE.md)을 사용한다.
- **AI가 참조하는 상세:** `details/vNNNN.md` — 복원 커밋, 해시, 실행 조건, 과거 평가를 보관한다. [작성 규칙](details/README.md)과 [상세 템플릿](details/TEMPLATE.md)을 따른다.

결과에 영향을 주는 변경 PR마다 버전 하나를 추가한다. 문서만 고치거나 같은 로직을
다시 평가하면 버전은 유지한다. 요약에는 최신 결과를 보여주고 과거 실행은 상세에 남긴다.

## 기본 평가 조건

**FIXED · 추출 Sol / 주체 해소 Terra / 비교 Sol · medium**, judge도 Sol·medium이다.
FIXED는 회차별 정답 시작 상태를 고정하는 평가 모드다. 실제 모델·회차는 각 요약에 적는다.
