## 변경 경계

- `schemas/analysis_source.py`, `schemas/worker.py`, `schemas/analysis_context.py`: 회차와 설정집의 명시적 출처 계약. 책 출처는 실제 리비전과 기준시점을 유지하며 null 회차를 만들지 않는다. claim·batch·context·projection의 책 출처를 고정 Job manifest와 비교한다. BOOK이 현재/입력 출처에 포함되면 양방향 슬롯 chronology를 비교한다.
- `models/setting_book_*`, `services/setting_book_*`, `services/ordered_analysis_fence.py`: 별도 책 청크와 원문 코드 포인트 offsets, UTF-8 SHA-256, Java와 같은 비공백 문자 수 검증. 작품/배치/현재 포인터/보관/lease/input·source hash/key/version/리비전/청크 소유권을 저장 트랜잭션 안에서 확인한다. 체크포인트 재개는 같은 frozen key/version의 원문을 다시 읽어 hash/count를 검증하고, 공통 splitter가 만든 text·index·offset·문단 경계와 저장 청크를 대조한다. splitter가 청크 밖에 남긴 선행/후행 빈 줄과 청크 사이 구분자를 허용하며 ID를 유지한다. 책 임베딩은 호출하지 않는다.
- `analysis_job_worker.py`: 같은 단일 실행에서 청크→인물 추출/저장/비교→세계관 추출/HTTP 발행/비교를 진행한다. Python은 최초 인물 후보만 SQL로 저장한다. 세계관 저장·검토·거절 fingerprint·정식 상태 적용·journal seal은 Backend API가 소유한다.
- 양쪽 extractor·주체 해소·comparator·projection·독립 복구: 문서명/리비전 번호와 안전한 provenance를 읽는다. 제목/표/목록을 문서 구조로 해석하며 문서 리비전·업로드 순서를 이야기 시점이나 회차보다 영구적으로 우선하는 출처로 쓰지 않는다. 미래·계획·불확실한 주장은 검토 대상으로 유지한다. 내부 ID/hash와 거절 정책은 prompt에 투영하지 않는다.
- 숨김 인물/세계관 재비교 Worker도 책 capability를 광고한다. 사용자가 요청한 `CONFIRMED_ONLY` 재비교는 ordered context 없이도 frozen book manifest와 비교 source를 검증한다. 기존 회차 요청·golden/parity 입력은 유지한다.

## 프롬프트·제품 조건

제품 모델·reasoning·출력 상한·기본 청킹 목표/최대/최소는 변경하지 않았다. 실제 유료 평가를 실행하지 않았으므로 운영값을 실측값으로 기재하지 않는다.

## 기준시점·직접 수정 보호 refinement — 2026-10-07

위 기본 구현/소규모 연결의 실행 기록은 그 시점 코드의 근거다. 아래 변경 후 실제 모델 품질이나 배포를 검증한 것으로 소급하지 않는다. 같은 미커밋 GH221 변경의 로직 v0006으로 기록한다.
