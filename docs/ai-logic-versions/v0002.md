# v0002 — OpenAI 응답 읽기 제한 300초

2026-09-11 · 적용: main · 이전: [v0001](v0001.md)

## 무엇을 바꿨나

- 기본 OpenAI Responses client의 응답 읽기 제한을 120초에서 300초로 늘렸다.
- 연결·전송·풀 대기 제한은 120초로 유지하고, 주입한 HTTP client 설정도 덮어쓰지 않는다.
- 진단용 평가에서만 캐릭터 1차 출력 상한 9,000과 응답 저장을 명시적으로 선택할 수 있게 했다.

신규 인물 평가와 provider 진단 변경은 제품 프롬프트·판단을 바꾸지 않아 같은 버전에 기록했다.

## 평가

**부분 완료 — Sol 실행은 503 실패, Terra 대조는 완료.**
2화 · FIXED · CHARACTER · 제품/judge medium

| 실행 | 추출 / 비교 / judge | 1차 F1 | 2차 채점 | 최종 상태 F1 |
| --- | --- | ---: | ---: | ---: |
| Sol | Sol / Sol / Sol | 미측정 | 미측정 | 미측정 |
| Terra 대조 | Terra / Terra / Terra | 85.11% | 11/11 (전체 Gold 15) | 82.44% |

Terra 대조의 judge API 호출은 0회였고, 결과는 Sol 대비 품질 우위나 안정성 개선율을 뜻하지 않는다.
Sol 재실행은 같은 첫 입력에서 provider 과부하 HTTP 503으로 중단되어 품질 지표를 계산하지 못했다.
다음: 제한된 503 재시도 정책을 검토하고 장애 회복 후 기본 Sol 조건으로 다시 평가한다.
