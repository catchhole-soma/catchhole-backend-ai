- **종족의 전투 특성:** 문장·수식어마다 속성을 나누던 안내를 저장할 정보 단위로 정리했다. `RACE / 종족명 / 전투 특성` 아래에 `마법 재능·신체 능력·전투 강점`을 구분하고, 원문에 있는 속성만 만든다. 체력·힘과 그 결과인 장비 착용 설명은 신체 능력 값으로 보충하며 명시적으로 독립된 능력치·판정 규칙은 유지한다.
- **기존 정보 보충:** 같은 경로의 신체 능력에 양립하는 설명이 추가되면 기존·신규 내용을 MERGE로 보존하고, 실질적인 반복만 EXCLUDE하도록 명시했다. 새 scope 생성 조건, 실제 target·전체 경로 검증, quote·offset 보존과 batch ADD의 canonical 경로 유지 기준을 함께 설명한다.
- **능력과 세계 공통 규칙:** POWER_SYSTEM은 능력 자체의 습득·발동 조건·자원·효과·제약으로 좁혔다. 특정 능력과 무관한 세계·게임 공통 사망·전투·진행 규칙은 WORLD_RULE_HISTORY, 종족의 선천적 적성은 RACE로 구분한다. enum이나 답지를 바꾸지 않는다.
- **버전 추적:** 세계관 추출 cache key를 평가 코드에서 문자열로 반복하지 않고 실제 extractor 상수에서 가져온다. 새 프롬프트가 사용됐는지 실행 결과의 버전으로 확인할 수 있게 했다.

### 함께 평가한 STATUS 처리

이번 평가에는 아래 STATUS 처리도 포함돼 있다. 이 내용은 2026-09-02
[AI #50](https://github.com/catchhole-soma/catchhole-backend-ai/pull/50)에서 반영한
[2d0b53a](https://github.com/catchhole-soma/catchhole-backend-ai/commit/2d0b53a29d043c182808ebf615cde506543328f1),
[0153fae](https://github.com/catchhole-soma/catchhole-backend-ai/commit/0153fae611790460f4eaaa4f5e13a913b0e4e609)의 변경이다.

- 1차 추출은 회차 시작의 활성 STATUS를 문맥으로 받고, 단순 반복을 제외하면서 시작·악화·완화·종료 결과를 후보로 남긴다. 직접적인 완치 선언이 없어도 치료 후 증상·능력·행동의 회복 근거를 사용한다. 치료 시도만으로 종료를 단정하지 않는다.
- 하나의 결과가 여러 기존 상태와 관련되면 관찰된 전환 후보 하나를 만들고, 종료할 상태와 operation은 2차에서 결정한다.
- 2차 비교는 같은 key에만 한정하지 않고 의미상 관련된 활성 STATUS를 검토한다. REMOVE는 target·proposal을 비우고 제거할 참조를 하나 이상 반환한다. 새 상태도 보존해야 하면 ADD/UPDATE/MERGE와 제거 참조를 함께 사용한다.
- 후보의 active=false는 그 후보 자체를 현재 snapshot에 추가하지 않는다는 뜻이며 다른 상태의 종료 근거를 대신하지 않는다. 회상·가정이나 치료 결과가 불확실한 경우에는 종료를 강제하지 않는다.

이후 [03800ad](https://github.com/catchhole-soma/catchhole-backend-ai/commit/03800ad0efdf512b564db63fd16e9f6075fe48bf)의
batch 비교에도 같은 종료 기준이 들어갔다. 위 커밋들은 v0001 기준 SHA의 조상이며,
캐릭터 추출·비교 구현과 해당 프롬프트는 v0001과 이번 평가 SHA 사이에 변경이 없다.
따라서 이번 결과는 STATUS 처리를 포함한 전체 평가지만 STATUS 종료 로직의 새 변경을
평가한 것은 아니다. main 병합으로 가져온 캐릭터 비교 v2→v3는 STRING proposal의
JSON 문자열 계약 보강이며 STATUS 종료 기준 변경과 구분한다.
