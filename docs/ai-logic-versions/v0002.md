- **종족의 전투 특성:** 문장·수식어마다 속성을 나누던 안내를 저장할 정보 단위로 정리했다. `RACE / 종족명 / 전투 특성` 아래에 `마법 재능·신체 능력·전투 강점`을 구분하고, 원문에 있는 속성만 만든다. 체력·힘과 그 결과인 장비 착용 설명은 신체 능력 값으로 보충하며 명시적으로 독립된 능력치·판정 규칙은 유지한다.
- **기존 정보 보충:** 같은 경로의 신체 능력에 양립하는 설명이 추가되면 기존·신규 내용을 MERGE로 보존하고, 실질적인 반복만 EXCLUDE하도록 명시했다. 새 scope 생성 조건, 실제 target·전체 경로 검증, quote·offset 보존과 batch ADD의 canonical 경로 유지 기준을 함께 설명한다.
- **능력과 세계 공통 규칙:** POWER_SYSTEM은 능력 자체의 습득·발동 조건·자원·효과·제약으로 좁혔다. 특정 능력과 무관한 세계·게임 공통 사망·전투·진행 규칙은 WORLD_RULE_HISTORY, 종족의 선천적 적성은 RACE로 구분한다. enum이나 답지를 바꾸지 않는다.
- **버전 추적:** 세계관 추출 cache key를 평가 코드에서 문자열로 반복하지 않고 실제 extractor 상수에서 가져온다. 새 프롬프트가 사용됐는지 실행 결과의 버전으로 확인할 수 있게 했다.

주요 파일은 `app/llm/prompts/world_setting_extraction.md`,
`world_setting_comparison.md`, `world_setting_comparison_batch.md`와
`app/analysis/world_setting_{extractor,comparator}.py`,
`evals/multi_stage_setting/runtime_adapter.py`다.
