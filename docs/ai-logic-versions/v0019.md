# v0019 — 세계관 보류 도메인 분리·입력 64k

2026-10-22 · 적용: PR #92, 배포 결과는 연결 Actions에서 확인

## 무엇을 바꿨나

- 세계관 내용 비교에는 세계관 보류만 전달한다. 인물 참고가 입력 예산을 차지하던 오류를 수정했다.
- 단독·묶음·복구와 토큰 계산에 같은 필터를 적용하고, 세계관 근거·순서·원본 고정 입력을 보존한다.
- 사용자 요청에 따라 입력 기본값을 32,000→64,000으로 늘렸다. 출력 한도는 16,000이다.

## 평가

상태: 자동 검증 완료 · 실제 모델 품질·운영 재분석 미측정

| 지표 | 결과 |
| --- | --- |
| 전체 자동 테스트 | 4,233 통과 / 134 skip / 기존 경고 1개 |
| 도메인 분리 회귀 | 단독·묶음·복구 × 혼합·대량 인물 참고 6개 통과 |
| 변경 전 18화 재시도 안전 예산 재구성 | 인물 참고 제외 전 32,325 → 제외 후 19,191 |
| 변경 전 33화 안전 예산 재구성 | 인물 참고 제외 전 34,224 → 제외 후 19,363 |
| 실제 추출·최종 상태 F1 / 2차 의미 정확도 | — / — |

토큰 수치는 저장 입력 재구성이며, 수정 후 실제 LLM 실행·정답률이 아니다.
회귀는 32k를 명시하여 기본값 인상으로 도메인 혼입 문제가 가려지지 않게 했다.

같은 도메인의 무관한 참고는 아직 포함된다. 관련성 선별은 [Java #284](https://github.com/catchhole-soma/catchhole-backend-java/issues/284)에서 별도로 구현·평가한다.
mkshie가 #284/#187에서 선별 기준·합격선을 고정한 후 FINAL Gold와 누적 실행으로 필요한 근거 누락·품질·비용을 확인한다.
