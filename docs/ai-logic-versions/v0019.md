# v0019 — 긴 생성 응답의 읽기 제한 900초

2026-10-22 · 적용: 작업 브랜치, 운영 미반영

## 무엇을 바꿨나

- Responses 기본 client의 읽기 제한만 300→900초로 늘렸다.
- 정상 설정집 추출 응답도 286~298초였고, 같은 요청이 300초 제한에서 반복 실패했다.
- 연결·전송·풀 제한 120초, 주입한 HTTP client, 재시도·모델·프롬프트·토큰 상한은 유지한다.

## 평가

상태: 부분 완료 — 오프라인 회귀 통과, 실제 900초 경로 실측 진행 중
조건: 실제 제품 HTTP·DB·Worker·OpenAI 경로, 빈 작품별 인물/세계관 설정집
