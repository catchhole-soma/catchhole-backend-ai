# v0049 — 검수 근거 부족 검색과 사실 전제 판정

2026-11-08 · [AI #139](https://github.com/catchhole-soma/catchhole-backend-ai/issues/139)

## 무엇을 바꿨나

- DB가 질문의 정확한 속성·시점·조건을 뒷받침하지 못하면 Worker가 최소 한 번 원문 검색 후 다시 판정한다. 검색 장애는 정상 판정으로 숨기지 않는다.
- 질문에서 신분·인원 같은 사실 전제와 희망·추측 내용을 나누고, 근거 없는 겸직·착각으로 불일치를 면제하지 않는다.
- 명시된 직업 변화·겸직·단순 희망은 유지하며, '대부분'이라는 설명을 절대 규칙으로 확대하지 않는다. 공개 저장 API와 운영 모델 기본값은 같다.

## 평가

상태: 최종 재검사 진행 중. 로컬에 운영100화·설정·검색 조각을 복사해101화의 인위 오류14개를 검사했다.
계획·오탈자는 Terra medium, 판정은 Sol medium이다. 실제 웹 운영 모델 조건과 다르며 기존 파일럿과 개선폭으로 비교하지 않는다.
