## 의미 검토와 미측정

원문 전체와 18관찰/8결정을 수동 전건 대조했다. 원문에 없는 친구·연인·쌍방 감정 생성은
관찰되지 않았고 양쪽 태도의 차이는 두 방향 관계에 남았다. 이전 v2에서 빠진 행동과
4화 인용 복사 실패가 이번에는 원문 검증을 통과했다. 출력 항목 자체가 달라 정량 개선폭은 계산하지 않는다.

미해결 13관찰은 모두 한쪽 이상의 name=null 때문에 실제 인물 참조를 얻지 못했다.
별도의 안전한 화자/역할 해소 없이 모든 HOLD가 나중에 자동 해결된다고 설명하면 안 된다.
회상 1건은 시점이 PRESENT로 잘못 분류됐으나 HOLD라 그래프에는 반영되지 않았다.
원문 전체에는 맞지만 선택한 인용만으로 설명이 충분하지 않은 관찰 3건도 남았다.
긴 이름과 짧은 이름은 별도 내부 노드로 남았으나 이번 활성 관계는 짧은 이름 쪽에만 있어
공개 그래프의 실제 중복 표시는 확인하지 않았다. 실험의 4회 비교 입력 모두 기존 관계 목록은
비어 있었으므로 MERGE/UPDATE/END·재활성화는 실모델 검증하지 못했고 자동 회귀만 수행했다.
비공개 전건 검토표는 `semantic-review.private.json`, SHA-256
`88bffc9189900da83b901f4fe4b7999d25018e12e9967ebcb5673ef4011206ca`다.
대화/배려 일부는 EXCLUDE되어 맥락이 축약됐다. 친구·연인 긍정 정답이 충분한 평가셋도 없다.
관계 precision/recall/F1, 최종 상태 F1, 캐릭터/세계관 Gold 점수는 모두 **미측정**이다.
후속 담당 작업은 안전한 화자·역할 연결 근거 확보와 관계 변화/종료가 포함된 회차 평가이며
