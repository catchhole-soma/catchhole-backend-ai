## 바뀐 동작

1. **키워드 희귀도 가중(`app/retrieval/search_repository.py`).** 1라운드 키워드 순위를 일치 단어 비율에서, 같은 조회 범위 청크의 문서 빈도로 구한 BM25 IDF `ln(1 + (N - df + 0.5) / (df + 0.5))`에 `ln(1 + x)`를 씌운 가중치의 일치 비율로 바꿨다. 한 글자 단어('레벨 업'의 '업')는 '업적'처럼 다른 단어 안에서도 일치하므로 가중치가 여러 글자 단어 가중치 중 가장 작은 값을 넘지 않는다(`d475bf4`). 모든 단어 일치 1.0, 단어 하나는 기존과 같고 후보 조건(한 단어 이상)·동점 순서(선호 회차 → 회차 → 청크 → ID)는 그대로다. 검수 실행의 `FrozenRetrievalRepository`는 `rarity_weighted_keyword=False`로 기존 순위를 유지한다.
2. **원문 계획의 등록 행 줄이기(`hybrid.trim_rows_for_source_answer`).** 원문 계획(`sourceNeed != NONE`, 항목별 계획 제외)에서 선택된 등록 행이 답변 입력을 넘치면 되묻기 대신 현재값 행 → 계획 정렬 순 이력 행으로 우선순위를 매겨, 원문 근거 예산(`evidence_tokens`, 문자는 토큰당 1.6자로 환산)을 비운 채 들어가는 최대 행 수를 이분 탐색으로 고른다(`REGISTERED_ROWS_TRIMMED`). 안내 문장도 답변 입력에 들어가므로 행 수를 고르기 전에 반영하고, 마지막 확인은 근거 자리 없이 해서 행을 하나도 남기지 못해도 원문 답변으로 계속한다(`10e3b64`. 이전에는 76행 중 19행으로 경계에 맞춘 뒤 안내를 붙여 넘쳤다). 등록 현재값 필수 계획이면 줄인 뒤 확인 여부를 다시 계산한다. `qa.fits`에 남길 자리 인자를 추가했고 기본값은 기존과 같다.
3. **원문 계획의 등록 모호성(`hybrid.current_requirement`).** 원문 계획(등록 현재값 필수 제외)에서 세계관 대상 후보가 여럿이거나(같은 이름이 두 분류), 대상은 찾았지만 FIELD 선택이 되묻기로 끝나면(`FIELD_CLARIFICATION` 표지) 그 대상은 등록 정보 없이 두고 원문 라운드를 계속한다(`REGISTERED_LOOKUP_AMBIGUOUS`). 인물 대상의 모호성, 등록 전용·등록 현재값 필수 계획은 기존대로 되묻는다.
4. **세계관 정확 이름(`qa_lookup.resolve_subject`).** 모든 후보 페이지를 읽었고 세계관 이름(NFC·대소문자 무시)이 정확히 같은 등록 대상이 하나뿐이면 그 대상을 쓴다. 인물은 계약(`docs/chat-qa-v1.md` 대상 선택 규칙 3)대로 정확히 같아도 되묻는다.
5. **행 선택 판단 불일치(`app/schemas/chat_qa.py`).** `AnswerSelection`에서 답하지 않는 판단에 붙은 행은 버리고, 답한다면서 행이 없으면 `INSUFFICIENT_EVIDENCE`로 바꾼다. 없는 참조·중복·상한 초과는 기존대로 재시도한다.
6. **plan v14(`hybrid_prompts.py`).** 따옴표로 인용한 대사의 화자·상대·앞뒤 장면 질문은 인용문을 검색어로 `PROCEED + SCENE`, '주인공'은 subjects에 넣지 않고 사건 단어로 원문 검색, 대화에 없는 '그 사람/그는' 지칭은 예외 없이 되묻기.

answer v16·근거 예산·모델·추론 강도·Spring 계약은 바꾸지 않았다.
