## 변경과 실행 계약

`app/validation`의 저장 baseline/원문 reader connector, full-span 계획, high 독립 관련 설정 선정/누락 보완,
보수적 병합, 고정 DB/직접·keyword·vector·인접 검색, 영수증 기반 medium FOLLOW_UP/DECIDED를 추가했다.

기존 추출·주체 해소·비교·chat 모델과 기본 reasoning은 바꾸지 않았다. count와 생성의 호출별 옵션을 일치시킨다.
직접 입력의 원문 부재와 필수 원문 실패를 구분한다. HUMAN/보호 flag는 명시 정정 scope가 아니다.

## 평가 상태

실제 Terra 모델·judge·Gold 품질 평가는 **미측정**이다. 외부 유료 provider 호출을 실행하지 않았다.
합성 모델 출력은 구조화 계획/검색/판정 연결과 보안·무결성 회귀만 검사한다. missed-hand 복원이나 prosthetic 사례의 통과를 Terra recall로 해석하지 않는다.
실제 PostgreSQL/Flyway·실제 Java↔Python HTTP와 provider/storage 대역을 각각 구분해 최종 로컬 실행 수치를 구현 보고서에 기록한다.
