## 최종 리뷰 수정 후 집중 회귀 — 2026-10-28-gh304-final-fix

첫 비교 묶음 전 숨김 캐릭터 그룹 실패는 후보 실행 링크보다 Job FAILED UPDATE가 먼저
flush되어 불변 알림의 대상 회차·유일한 원본 출처가 누락될 수 있었다. Java 제품 `63d104c`는
유효한 그룹 후보 링크를 같은 트랜잭션에서 먼저 flush해 직접 실패와 lease 회수 한도 초과를
함께 보완한다. 이후 live 상태로 과거 outbox를 재구성하지 않으며 stale 입력 no-op과 rollback을 유지한다.
Python 제품·테스트/helper는 위 SHA와 동일하고 이번 수정에서는 변경하지 않았다.
