### 검증한 의미

선정 밖 계정은 제외하고 bootstrap 반복은 중복 등록하지 않는다. 1화 처리 후 새 core3화를
추가해도 2→3 순서로 진행하며 모두 끝나기 전 공개 세대는0, 완료 후1로 바뀐다.
1·2·3화 각각 cutoff 관계가 보이고 기존 캐릭터·세계관·후보·청크 생성은0이다.
raw 사용량과 사용자 차감 분리를 실제 Java 토큰 원장/HTTP로 확인했다.
Java는 배포 전에 성공한 회차, 동일 원문의 관계 호출 원장이 있는 회차, 중간 삽입에 따른
후행 재비교를 서비스 부담으로 처리한다. 위 새 3화의 220 차감은 기존 관계 호출이 없는
최초 실행 사례이며 운영상 재작성 비용과 구분한다.

### 미측정과 다음 확인

캐릭터/세계관 Gold P/R/F1·가중치 재현율·최종 상태 F1, 관계 의미 정확도는 모두 **—**다.
기존 프롬프트를 바꾸지 않았더라도 과거 작품의 새 관계 결과 정확도가 검증됐다는 뜻은 아니다.
이번 요청은 자동 백필 실행 경계 검증이므로 추가 유료 LLM 평가를 하지 않았다.
배포 후 담당자는 campaign의 BLOCKED/완료 상태, 실제 raw 비용, cutoff별 관계와 근거를
표본 확인한다. 수치 비교가 필요하면 동일 원문·Gold·모델·judge 조건의 별도 평가로 남긴다.
이 PR만으로 운영 백필 완료를 선언하지 않는다. Java API 먼저, AI Worker 다음 배포가 필요하다.
