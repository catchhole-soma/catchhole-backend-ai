`WorldSettingComparator.prepare_batch_input`에서 `ordered_reference_data(..., domain="worldSettings")`를 사용한다. 단독·묶음·복구와 예산 계산이 같은 투영을 사용한다. 인물 보류를 제외해도 남은 세계관 참고의 순서·내용·근거와 서버 고정 입력은 보존한다. 대상별 관련성 선별은 이번 변경에 없다.

사용자 요청으로 세계관 내용 비교 입력 기본값을 32,000→64,000으로 변경했다. Settings·호환 fallback·Worker Compose·로컬/운영 환경변수 예제를 일치시켰다. 출력 16,000과 인물 입력 256,000, 모델·추론 강도·지시문·응답 schema는 유지한다. 환경변수 명시값은 기본값보다 우선한다.

시스템 지시문을 바꾸지 않아 cache key는 기존 `world-setting-comparison-batch:v16:ordered-provisional-v8` 및 `world-setting-manuscript-comparison:v1`을 유지한다. 설정집/현재 출처 관련 기존 suffix도 유지한다. 변경된 사용자 입력에 대한 실제 cache hit는 측정하지 않았다.

API·DB migration은 없다. 복원 시 위 코드 SHA를 기준으로 필요한 변경만 되돌리는 새 PR과 새 main 이미지 배포를 사용한다. 실패 작업 재개·사용량 정산·자동 반영은 기존 서버 경계를 따르며 저장된 보류나 Job 상태를 직접 바꾸지 않는다.

## 운영 원인 진단 — 변경 전 입력 재구성

2026-10-22 운영 코드 `0c1fb16b88413cbb82ed5935e891ad5640034132`의 Worker 로그·Tempo trace와 읽기 전용 DB 입력으로 확인했다. 원문·개별 설정·고정 입력 snapshot은 공개 문서에 포함하지 않는다. 진단 집계는 워크스페이스의 비공개 `output/catchhole-barbarian-1-60-20261022/failure-diagnosis/input-token-breakdown.json`에 있다. snapshot 해시·정식 평가 fixtureHash는 기록하지 않아 독립적인 공개 재현 자료로 취급하지 않는다.

| 입력 | 전체/인물/세계관 보류 | 기존 안전 예산 | 인물 참고 제외 재구성 예산 |
| --- | ---: | ---: | ---: |
| 18화 실패 재시도 | 84 / 71 / 13 | 32,325 | 19,191 |
| 33화 실패 | 101 / 81 / 20 | 34,224 | 19,363 |

안전 예산은 지시문·사용자 입력·응답 schema의 추정량에 10%와 256토큰을 더한다. 18화 값은 최초 실패가 아닌 재시도 snapshot이다. 이는 수정 전 코드로 입력만 재구성한 값이며 수정 후 실제 LLM 응답·품질·완료를 입증하지 않는다.

SSM 조회에서 실행 중 인물 입력 256,000·세계관 입력 32,000을 확인했다. 운영 `worker.env`에는 세계관 내용 비교 입력의 명시적 override가 없어 새 Compose 배포 시 64,000 기본값이 적용된다. 인물 단계는 18화 2묶음·9건, 33화 4묶음·13건을 비교 실패 없이 완료했으나 각 인물 요청의 실제 입력 토큰 수는 수집하지 않았다.
