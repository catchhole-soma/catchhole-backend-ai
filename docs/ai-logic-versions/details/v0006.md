### 변경 1: 추론 설정의 기본값과 GPT-6 요청 전달

- `app/core/config.py`의 환경변수 누락 기본값을 `none`에서 `medium`으로 바꾼다. 명시한 환경변수·dotenv 값의 기존 우선순위는 유지한다.
- `app/llm/openai_client.py`가 GPT-6 계열에서도 설정한 `reasoning.effort`를 보낸다. GPT-6에 명시한 값은 임의로 누락·변환하지 않으며 모델별 미지원 값은 공급자 오류로 드러난다.
- 기존 비추론 모델과 o-series의 호환 처리는 유지한다. 실제 HTTP 요청을 포착하는 테스트에서 설정값·환경변수·모델 override 경계를 확인했다.
- Worker 예제와 설명 문서도 기본값 및 전달 규칙에 맞춘다. 제품 모델 이름의 기본 라우팅은 이번 변경으로 교체하지 않는다.

### 변경 2: CHARACTER 1차 상태 추출 범위

- `app/llm/prompts/character_setting_extraction.md`에서 일시적인 감각·반응과 장면 전환만 설명하는 상태를 제외한다. 기절·잠듦·깨어남이 장면을 잇는 반응에 그치고 독립적인 부상·질환·능력 이상·명시적인 지속 효과를 설명하지 않으면 시작·종료 후보를 만들지 않는다.
- 반응 때문에 당연히 행동이 멈췄다는 사실만을 구체적인 능력 제약으로 확대하지 않는다. 기존 활성 상태의 변경·종료와 사망·부활은 제외 기준보다 우선한다.
- 원문에서 구체적인 능력·제약·효과가 확인되는 상태의 시작·악화·완화·종료를 보존한다. 지속 시간이 짧거나 같은 회차 안에서 끝났다는 이유만으로 제외하지 않는다.
- 현재 원문과 `active_character_statuses`로 판단하며 이후 회차의 지속·재발을 추측하지 않는다. 기존 상태의 단순 반복 제외, 치료 결과 확인, 관련 상태의 종료 판단을 2차에 맡기는 계약은 유지한다.
- 명시적 스킬의 발동 조건·효과·재사용 대기시간은 능력 규칙으로 보존하며, 일시 적용 사실만으로 별도 STATUS를 복제하지 않는다.
- 추출 캐시는 v10→v11→최종 `setting-extraction:v12`로 올렸다. schema fingerprint 방식과 user payload·응답 schema·모델·출력 상한은 유지한다.
- 역사 요청 capture는 보존하고 `tests/fixtures/character_state_scope_request_overrides.json`에 추출 요청의 전체/system hash와 cache key만 별도로 기록했다. 세계관 프롬프트·분류, Gold·채점기·judge는 변경하지 않았다.
- `AGENTS.md`에 순간 상태 제외, 기존 활성 상태 변경·종료 및 사망·부활 우선, 회차 안에서 끝남만으로 제외하지 않는 기준을 기록했다.

### 결과 해석과 남은 검증

- 장면 반응에 해당하는 캐릭터 STATUS 후보는 baseline 3개, v11 2개, v12 0개다. v11은 순간 감각 후보 하나만 제외해 요청한 범위에 미달했고, 독립적인 상태 근거가 없는 기절·각성 반응을 시작·종료로 만들지 않는 일반 조건을 보강했다. 최종 실행에서 프로필 종족 설정의 추출은 유지됐다. 원문·인물명·Gold 예문을 프롬프트에 넣지 않았다.
- 기존 활성 상태의 종료, 사망·부활, 같은 회차에서 끝나는 실질적 제약·효과 보존은 이번 1화에 검증 사례가 없다. prompt 계약과 오프라인 회귀 확인 범위로 남기며 실제 LLM 검증 완료로 설명하지 않는다.
- Gold·원문·시작 상태·회차·모드·native scorer·judge·모델·추론 강도·실행 제한은 동일하고 제품의 전후 변수는 캐릭터 추출 프롬프트 및 cache다. 세 실행 모두 추론 전달 수정이 들어 있으므로 이 비교로 그 수정 자체의 품질 효과를 측정하지 않는다.
- 세계관 추출 요청 fingerprint는 세 실행에서 동일하지만 모델 출력 변동으로 v11의 세계관 예측 수와 점수가 달랐다. 세계관 프롬프트를 수정하지 않았으므로 해당 변화는 캐릭터 정책의 세계관 품질 개선으로 해석하지 않는다.
- 스냅샷의 `FINAL` 표시는 사용자의 내용 검수 완료를 뜻하지 않는다. `gold-v3-draft.4`의 정답 누락·hard negative 의미 대응 누락 가능성은 남아 있어 EXTRA를 실제 오답으로 단정하지 않고 점수 변화와 설정 유효성을 구분한다. 답지에 맞춰 예측·제품 기준·judge 판정을 수정하지 않았다.
- 각 조건의 1화 단일 실행이며 모델 출력 변동성과 캐시 입력량 차이가 포함된다. 일반적인 개선 폭, 반복 검증된 성능, 1~10화 전체 성과로 확대하지 않는다. 과거 GPT-5.6 1화 결과는 다른 제품 모델의 역사 참고이며 이번 GPT-6 전후 비교 baseline으로 사용하지 않는다.
