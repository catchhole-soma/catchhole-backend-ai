## 평가 — YYYY-MM-DD-run-id

추가 실행은 이 절에 새로 남긴다. 실제 값만 적으며 기본값으로 과거 기록을 채우지 않는다.

| 항목 | 기록 |
| --- | --- |
| 상태 / 담당자 / 실행 근거 | 완료·부분 완료·실패·미측정 / 작성자 / 시각·시간대·run URL |
| 실제 코드 SHA / 채점기 SHA | 전체 SHA 각각; 미커밋 변경 유무 |
| 평가기·입력 | reportVersion·dataset version·fixtureHash·characterSchemaHash; 원문/Gold/상태 snapshot 해시·비공개 보관 위치 또는 확인 불가 |
| 대상·상태 정책 | 회차·시나리오/의존 수·domains·mode·stateApplicationPolicy |
| 제품 모델·프롬프트 | 추출/주체 해소/비교·reasoning·fallback·실제 cache key |
| judge·실행 제한 | judge on/off·모델·reasoning·cache·세계관 판정 정책; maxChunks·청킹·출력/재시도 설정 또는 고정 코드 링크 |
| 실행 입력 / 산출물 | 실제 명령·Actions 입력; artifact ID·만료·score.json 해시 |

| 도메인 | 1차 P / R / F1 | 값 정확도 | 2차 처리 / 전체 결정 정확도 | 최종 상태 F1 | 미판정(1차 / 2차 / 최종) |
| --- | --- | --- | --- | --- | --- |
| 캐릭터 | — | — | — | — | — |
| 세계관 | — | — | — | — | — |

- 1차 정답/예측 수와 2차 실제 채점/전체 정답 수:
- 런타임 실패 / 상태 적용 오류 / 의존 상태 오류 / 전이 미판정:
- 소요 시간·토큰 사용량·비용: 보고서에 있는 값만 기록하고 null은 유지.
- 결과 해석·비교 조건·남은 문제:
- 미측정·실패·부분 완료 사유와 다음 조치: 담당자·재평가 시점/조건.
