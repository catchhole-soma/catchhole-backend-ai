## 바뀐 동작

1. **대상 참조(AI-1).** PLANNER/COVERAGE/RELATED_SELECTION 입력에 `target_source_ref: "T1"`, schema의 span `source_ref` enum `["T1"]`. 검증 전에 대상 segment 별칭 `TSEGn`을 `T1`으로 바꾼다(span, TARGET_CONTEXT 의무, JUDGE span, 오탈자 span). `validate_span`은 그대로 엄격하다.
2. **위치(S2).** quote가 정확하지 않은 위치에 있으면 같은 quote의 정확한 위치 중 모델 start에 가장 가까운 곳으로 다시 계산한다. 후보는 구간 범위 안(설정: 구간 문맥, 오탈자: 핵심 구간 start·문맥 end)이며 정확한 span은 옮기지 않는다. 없는 quote·같은 거리 반복은 거절한다.
3. **조건부 판정(S4·S5)·required_reads·target_spans.** strict mode root는 조건부 필드를 표현할 수 없어 prompt와 검증기로 맞췄다. FOLLOW_UP의 판정 필드는 무시하고, NO_CONFLICT의 impact/impact_reason은 null로 둔다. `required_reads.receipt_refs`와 DECIDED `target_spans`는 서버 소유 값으로 확정한다(인용한 receipt가 없거나 원고에 없는 인용이면 거절). 나머지 completion 항목은 근거·receipt를 하나 이상 인용해야 한다.
4. **COVERAGE 입력(S3)·참조 형식(S6).** COVERAGE는 `subject_catalogue`(식별)와 선택 `settings`·`rule_refs`를 따로 받는다. lookup intent는 연산별 anyOf다. COVERAGE·BOOK_COVERAGE·RELATED_SELECTION은 선택 rule·CL·page를 enum으로 열거한다(항목당 100·schema당 500). PLANNER·JUDGE는 보고서 안에서 schema를 고정하고 종류별 pattern으로만 제한한다(prompt cache 유지). 계획·후속 조회 의무는 저장·revision 전에 읽을 수 있는지 검사한다.
5. **VECTOR.** frozen RAG가 없고 회차 출처가 있으면 schema가 KEYWORD만 제안하고, VECTOR 의무는 저장 전에 `VECTOR_NOT_READY`로 거절한다. 검색이 주입된 실행과 설정집만 있는 실행은 그대로다.
6. **진단.** `IncompleteInspection(code, cause)`와 `InspectionResult.failure_cause/failure_stage/normalizations`를 추가했다. `INVALID_INSPECTION_CONTRACT` 분류는 유지하고 원인(`INVALID_EXACT_SPAN` 등)·단계(`PLANNER:TSEG1`)·정규화 횟수를 로그에 남긴다. Worker는 Complete `failureCode`로 원인 코드를 보낸다. runner는 `app.validation` 로그만 INFO로 출력한다.

판정 내용·사유·영향 등급·질문 병합 키·검색/근거 수집·예산·모델·추론 강도는 바꾸지 않았다. 5~6의 VECTOR·cache·target_spans 보완은 아래 실제 재실행에서 드러난 원인을 같은 브랜치에서 고친 것이다.
