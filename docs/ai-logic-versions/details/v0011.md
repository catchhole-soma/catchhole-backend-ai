## 변경

1. 원문에 명시된 승인된 지속 속성 변경을 추출·단건/묶음 비교에서 보존한다. 과거 현재값과 새 현재 변화의 전후 관계를 유지하고 미승인 미래·소문을 현재 사실로 승격하지 않는다.
2. 비선택 DISTINCT/RELATED proof는 실제 target ref·중복 ref·원문 연속 인용을 검증한다. 선택 SAME_ENTITY의 이름·별칭·부모 충돌 보호를 유지하고 비선택 근거를 연결 권한이나 target memory 근거로 누적하지 않는다.
3. baseline의 main scope 정책과 BOOK 출처·시점·CURRENT/보호·회복 경계를 유지한다. 공통 recovery·schema·Worker·OpenAI client·evaluation adapter는 baseline과 동일하며, BOOK source/time/current/protected 경계를 유지한다.

2026-10-14의 **12 generation/12 receipt와 10단계/10후보 HTTP 성공**은 [기존 #82 상세](../branches/gh-221/details/v0010.md)의 당시 실행 조건·코드 기준으로 보존한다. 원16응답 회귀도 새 generation으로 세지 않는다. 이번 namespace와 통합 tree에서 새 paid API·실제 HTTP 품질 실행을 수행했다는 뜻이 아니다. 과거 원문·Gold·raw·점수·STOP 기록을 수정하거나 새 전체 F1·개선폭으로 소급하지 않는다.
