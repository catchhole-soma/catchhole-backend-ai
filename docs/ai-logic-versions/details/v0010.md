## 최소 변경 경계

1. 세계관 추출·단건 비교·묶음 비교 지침에서 승인된 지속 속성의 실제 변화와 전후 관계를 보존한다. 과거 현재값이 문맥에 있어도 원문에 명시된 새 현재 변경 후보를 생략하지 않는다. 미래 계획·미승인 제안·소문을 현재 사실로 승격하지 않는다.
2. `app/analysis/book_world_identity.py`는 비선택 DISTINCT/RELATED 근거를 해당 검증 경계에서 다룬다. 기존 target ref와 중복 ref, 실제 원문 연속 인용을 검증하며 선택 SAME_ENTITY의 이름·별칭·부모 충돌 검사를 유지한다. 새 helper·공개 DTO·LLM 단계·자연어 후처리 분류기를 추가하지 않는다.
3. 제품 파일은 identity validator·세계관 prompt3개와 namespace 문자열을 갱신한 extractor/comparator, 총6개다. extraction v4→v5, 단건 비교 v16→v17, batch v13→v14, BOOK subject suffix book-grounded-identity-v1→v2를 갱신했다. 일반 ordered subject v4는 유지한다. 실제12 API는 동일 최종 prompt 본문·이전 namespace에서 실행한 증거이며, 새 key로 실행한 결과로 소급하지 않고 namespace-only 변경 뒤 회귀를 별도로 확인한다. 재호출은 하지 않았다. namespace 최종 변경 뒤 관련 회귀144건과 최종 전체2,611통과/45skip/경고1을 확인했다.

기존 upstream 대비 설정집 기반 전체 WIP는 이 최소 delta가 아니다. 선행 기반·정책 PR와 이번 fix를 분리하며 기존 기반 없이 main에 단독 적용 가능하다고 주장하지 않는다.
