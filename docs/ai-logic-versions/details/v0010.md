## 통합 동작

main의 챗봇·검색·세계관 의미 비교/실패 격리와 #221의 설정집 고정 출처·기준시점·현재값/이력 보호 및 정확 입력 토큰 경계를 같은 코드에서 유지한다. 아래 회귀는 통합 baseline의 결과다. 후속 #82 결과와 구분한다.

- **scope 정책 결정:** 사용자가 main의 의미 비교 정책 유지를 선택했다. scope가 비어 있고 같은 설정명의 기존 속성이 특정 scope 아래에 있다는 이유만으로 concrete UPDATE/MERGE/EXCLUDE 또는 root ADD를 SCOPE_UNRESOLVED로 바꾸지 않는다. 같은 category·canonical 주체의 경로·값·원문 근거로 같은 사실인지 판단하며 실제 지역·시점·조건·하위 집단·확실성 차이는 보존한다. 모델이 검토로 판단한 경우는 검토로 유지한다. 이전 자동 scope-review의 내부 `explicit_root_scope_evidence_index` 필드와 prompt 지시는 제거했으며 일반적인 원문 근거 기반 root ADD 지침은 유지한다. retry 지시도 빈 scope·동명만으로 자동 검토를 강제하지 않는다. 기존 #221의 반대 정책과 당시 결과는 보존 이력에 남긴다.
- main 공통 세계관 recovery와 정상 decision salvage·dependency 단위 재시도를 유지하고, initial/retry/group/final validation 전체에 `analysis_source`를 전달해 BOOK 주장·기준시점·CURRENT 시점·보호 경계를 적용한다.
- Worker 생성자는 BOOK 서비스와 main retrieval 설정을 함께 받는다. BOOK은 EPISODE용 retrieval 준비 전 반환하며 신규/재개 EPISODE는 기존 bounded retrieval 준비를 유지한다. 정확 입력 count와 생성은 같은 입력·reasoning·schema를 사용하며 main GPT-6 `none` 지원도 유지한다.

## Prompt cache 기준

통합 baseline은 세계관 단건 `world-setting-comparison:v18`, 묶음 `world-setting-comparison-batch:v15`, ordered suffix `ordered-provisional-v8`를 사용한다. 이미 발행한 #82의 서로 다른 본문이 단건 v17/묶음 v14를 사용하므로 해당 namespace를 재사용하지 않는다. BOOK `setting-book-claims-v2`·`book-current-time-v3`와 캐릭터 단건 v15/묶음 v10은 유지한다. 후속 #82 통합의 실제 namespace는 별도 v0011 상세에 기록한다.
