- 계획(`planning.py`, 신규): 모든 구간 병렬 PLANNER, 핵심 구간 안 span만, 즉시 게시, 서버 v4 grid 대조(`GRID_SEGMENTS_MISMATCH`), 구간 순서 병합.
- 판정(`judging.py`, 신규): OPEN→(검색·문맥)→FINAL, 충돌 의심 Worker VECTOR 변화 검색, 질문당 최대 3회, ±300 code point 대상 문맥, 압축 현재값 행만,
  `SettingsCache`(SETTINGS 100개 묶음·중복 요청 합침), 판정 검증(SUSPECTED는 CHANGES_EXCEPTIONS VECTOR receipt 필수).
- 조율(`service.py`): INPUT·T1·SUBJECTS → 계획 → MERGED_PLAN → 판정 4개 동시(TaskGroup). FINAL_VALIDATE·BOOK·COVERAGE·SUBJECT_RESOLUTION·기계 단서 제거.
  실패 정책 `failures.py`(운영 fail-fast, 실험 계속). 결정 없이 남은 질문은 `JUDGING_INCOMPLETE`로 보고(완료로 숨기지 않음).
- RAG(`corpus.py`, `search.py`): VECTOR만, 실행당 lock 하나·같은 문장 1회 검색(`reused_from`), 조각별 READ_SOURCE 재확인 제거, 과거 회차 0개면 NOT_APPLICABLE,
  SQL readiness 숫자(Decimal)를 receipt에서 정수로.
- 모델(`models.py`, `schemas.py`): `RoleRuntime`, `PLANNER_SYSTEM`(질문 확대·"나/너/그" 장면 문맥 판단·문맥 읽기 전용)·`JUDGE_SYSTEM`(현재값 우선·FOLLOW_UP 조건·FINAL은 결정),
  schema `validation_planner_v3`·`validation_judge_open_v3`·`validation_judge_final_v3`(SCHEMA_VERSION v3).
- 실행(`execution.py`, `client.py`, `data.py`, `checkpoint.py`, worker): claim `projectionVersion=2`·`configurationVersion=2`, `claim_roles`, 역할별 metered client,
  query embedding lock, SUBJECTS/SETTINGS 읽기, MERGED_PLAN `lookup_obligations: []`, runtime checkpoint·`/revisions` 제거, TYPO도 `RoleRuntime`.
- `clues.py` 삭제. 공통 fixture·문서·실험 harness(`scripts/validation_experiment/`) 추가.

모델·추론 강도: 코드 상수 없음. 운영 권장(Backend 설정) PLANNER `gpt-6.1-terra` medium, JUDGE·TYPO는 31화 비교 뒤 결정(판정 medium, 오탈자 low).
