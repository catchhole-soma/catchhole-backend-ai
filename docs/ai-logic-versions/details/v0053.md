## 구현

- `book_character_context.py`: 전체 catalog와 선택 상세를 K ref로 분리한다. 원 이름·별칭·확정 여부를 catalog에 한 번만 싣고 상세의 식별 인용을 한 번만 보낸다.
- 모든 비어 있지 않은 행이 `이름: 내용` 형식이고 이름/별칭/짧은 이름 구성어에 대응할 때만 상세를 선택한다. 한 글자 짧은 이름·동명·공유 성씨는 해당하는 모든 후보를 보존하고, 내용에 직접 언급된 다른 인물도 함께 남긴다. 헤더를 숫자 접두 연대·긴 단어의 일부 이름으로 해석하지 않는다.
- 일반 서술·주체가 명확하지 않은 행·전역/집단 표현이 하나라도 있으면 전체 상세를 유지한다. 단순히 문서 어딘가에 이름이 있다는 이유로 다른 문장의 범위를 제한하지 않는다. 구조화된 행 안의 복잡한 간접 지칭은 실제 모델 품질 평가 대상으로 남긴다.
- current_slots의 값·구조값·유형·key를 모두 보존하고, 동일 STATUS key와 표시값만 active_status 출처/보호/시점과 결합한다. 서로 다른 값·명시 종료 상태는 원래 두 표현을 유지한다.
- 전체 frozen carrier와 검증·후속 해소·비교를 수정하지 않는다. 설정집 기준시점·원문·schema·response schema·모델·출력 상한·64,000 guard를 유지한다.
- BOOK ordered+semantic가 함께 있는 호출만 바뀐다. legacy/EPISODE와 world는 기존 경로다. 재시도는 동일 투영에 기존 correction을 덧붙이고 다시 guard를 검사한다.
- cache suffix `:book-character-context-v1` + 기존 STATUS forecast suffix.

## 실제 실패 7건의 재구성 측정

7건은 모델 호출 전 `ordered_required_context_exceeds_input_limit`로 실패했다.
당시 job별 청크·현재값·보류 참고를 복원하고 저장 input_state_hash와 fingerprint를 확인했다.
R1/R2는 과거 snapshot·fact 이력으로 복원했고 이후 5건은 당시 상태와 일치하는 현재 자료로 복원했다.
전체 요청의 저장 원본이 없으므로 provider가 실측한 input_tokens로 표현하지 않는다.
원래 보고한 7건의 raw/guard 수치와 모두 동일함을 먼저 검증했다.

운영 Worker의 별도 읽기 전용 프로세스에서 기존/변경 extractor를 메모리로 불러와 실제 provider 경계의
system/user prompt를 포착했다. 외부 호출 client는 항상 거절한다. 실제 배포 파일과 DB는 변경하지 않는다.
원문·고객 이름·이메일·S3 경로는 이 문서/JSON/합성 fixture에 복사하지 않았다.
비공개 재현 도구는 원 워크스페이스 `output/gh147-setting-book-context/private/real-token-replay.py`, 결과는
`output/gh147-setting-book-context/real-token-reviewed.txt`에 보관했다(저장소 밖). 운영 원자료가 바뀌거나
배포 기준 코드가 달라지면 fingerprint/기준 수치 검증을 통과한 상태로 다시 복원해야 한다.

## 자동 검증과 남은 범위

- 최초 새 provider 회귀 13개는 기준 코드에서 BOOK 투영이 없다는 기대 이유로 실패했다. 구현 후 통과했다.
- 같은 이름·별칭·짧은 이름·공유 성씨·연대 오탐·전역 fallback·STATUS 값/보호/시점·미확정 인물·보류 순서·원입력 불변·재시도·잘못된 ref·큰 문맥 guard를 검사한다.
- baseline 전체 5,720 통과 / 186 skip / 기존 경고 1. 최종 전체 5,748 통과 / 186 skip / 동일 경고 1 (33.35초). 새 provider 회귀 28개 통과. Ruff 대상 파일 검사와 git diff --check 통과. skip에는 별도 DB/외부 실행 조건이 필요하며 실제 통과로 세지 않았다.
- 실제 LLM 인물/설정 추출 precision·recall·F1, 관계/2차 처리·최종 상태 F1, 지연·과금은 미측정이다.
- 자연어 간접 지칭과 문서 간 문맥 선택은 합성 회귀만으로 품질을 입증할 수 없다. 배포 전 담당 구현자가 실제 설정집 표본의 인물 누락/현재값 판단을 별도 평가해야 한다.
- 실제 실패 7건은 입력 guard 통과까지 검증했고 전체 분석 성공으로 표현하지 않는다.
