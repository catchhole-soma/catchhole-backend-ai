## 변경·실행 조건

- `app/core/config.py`의 캐릭터·세계관 1차 추출 기본 출력 상한을 각각 32,000, 출력 절단 시 한 번의 확장 상한을 각각 64,000으로 맞춘다. 이전 기본은 캐릭터 6,000→12,000, 세계관 5,000→10,000이었다.
- `.env.example`, `deploy/worker.env.example`, `deploy/compose.worker.prod.yml`에도 같은 네 기본값을 반영한다. 기존 환경변수의 명시적 값은 기본값보다 우선한다.
- 모델·reasoning·프롬프트·cache key와 일반 JSON/schema 재시도 로직은 변경하지 않는다. 출력 상한은 reasoning과 visible output을 함께 포함하며 확장 호출도 기존 예약·정산 경계를 따른다.
- `app/worker/analysis_job_worker.py`의 BOOK 전체 원문 동명 identity 검증은 기존 주체 해소 모델을 사용한다. 최초 출력 상한은 주체 해소·캐릭터 추출 설정 중 큰 값, 절단 재시도는 캐릭터 추출 재시도 설정을 사용하므로 새 기본에서 32,000→64,000이 된다. 호출 경로나 일반 주체 해소 기본 2,000은 변경하지 않는다.
- 평가 workflow의 `extraction_max_output_tokens` 6,000/9,000 최초 override는 보존한다. 해당 평가의 절단 재시도는 runtime 설정을 따르므로 현재 기본은 64,000이다. 과거 12,000 재시도 기록·Gold·원문·점수는 수정하지 않는다.
