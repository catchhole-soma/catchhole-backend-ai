## 실제 변경

`app/validation/typo.py`가 `ValidationDataClient` 전문 읽기/최종 검증,
공통 `TypoCheckInput`·`Span`·`split_segments`·`SegmentCoverage`·결과와 예산을 연결한다.
`app/llm/prompts/typo_check.md`는 이 역할의 신뢰 경계·검사 범위·응답 형식을 지시한다.
`ClassifiedTypoSuggestion`/`ClassifiedTypoCheckResult`는 공유 타입을 상속하고 category만
가산한다. 공통 파일 수정이나 설정 검사 내부 타입에 대한 의존은 추가하지 않았다.

Astra Important1 재현 뒤 R1에서 주입 client를 raw OpenAIResponsesClient 또는 그 raw를 직접
감싼 MeteredTextGenerationClient(max_retries=0) 한 층으로 제한했다. 기본 max_retries=3 wrapper는
model_calls=1에도 503→성공에서 provider/예약 2회 후 완료할 수 있었다.
이제 retry/중첩/unknown proxy/subclass/cycle은 source/provider/원장 전에 고정 구성 오류로 거절한다.
공통 wrapper나 전역 기본값은 바꾸지 않았다. 정상 zero wrapper는 실패/성공 모두 provider/예약 1회다.

start 소유 구간과 exact code point 위치, 문맥 한계, 중복/겹침, 전체 coverage와 제안 일관성을
batch 전체에서 검증한다. 한 독립 구간 실패는 나머지 성공을 보존하되 미완료다.
원고 변경/파기/최종 재검증 실패는 이전 제안 전체를 무효화한다. 원문 자동수정은 없다.
