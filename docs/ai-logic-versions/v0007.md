# v0007 — 충돌 판정·검토 연결과 설정한 추론 강도 전달

2026-10-09 · 적용: 작업 디렉터리, main·운영 미적용 · 이전: [v0006](v0006.md)

## 무엇을 바꿨나

- 값 차이·정정 선언은 검토하고 자동 UPDATE는 명시적 변화 과정과 전후 상태를 요구한다. 표현 차이·양립하는 보완·명시적 제한 예외는 기존 의미를 보존한다. 현재 지속 속성의 시작 수식과 종료된 이전 속성, 확정된 현재 미정 상태와 근거 불확실성을 구분한다. 직접 현재 사실과 별도 관계의 불확실성도 구분해 양립하는 같은 항목을 MERGE로 보존한다. 원문이 명시한 일반 규칙의 root 추가와 기존 좁은 예외의 보존을 함께 허용한다.
- 인물 묶음의 확정 현재 충돌은 기존 참조를 읽기 전용으로 연결하고 실제 기여자만 의존성으로 전달한다. 세계관은 검증한 실제 현재 경로에 한해 CONFLICT 검토로 기존값과 새 원문값을 함께 보존한다.
- 양립하는 목적지 MERGE와 명시적 정상 변화에는 선택적인 PRESENT BOOK 기준시점 공백을 허용한다. 알려진 변경 선후·보호·출처·이동·수동 경계는 유지한다. 공통 client는 설정한 Sol max를 실제 요청에 전달한다.

## 검증과 한계

상태: **작업 2 회귀 기록 보존, 후속 현재/과거·현재 미정 상태·직접 현재 사실·명시적 일반 규칙/예외와 긴 문서의 실제 의미 개선은 미검증**.

작업 1 당시 동일 고정 입력 5종 × 단건/후보 1개 묶음의 실제 Sol max 비교는 이전 prompt **5/10**, PR1 prompt **10/10**이었다.
20회 모두 요청/응답 max·기본 속도를 확인했다. 당시 인물 target=null 계약의 기록이며 현재 작업 2 검토 연결의 의미 검증은 아니다.
앞선 medium 관찰 원본과 정정 근거도 보존했다. judge·다단계 F1·전체 결정 정확도는 측정하지 않았다.

작업 2 당시 최신 전체 **2,484 통과·0 실패·0 제외**, 기존 경고 1개. 기존 격리 DB와 고정 Java 자료를 재사용했다.
고정 응답 회귀는 참조 전달·비투영·실제 의존성·값/근거 보존과 보호만 증명한다. 모델의 의미 판단 성공은 작업 4에서 검증한다.
실제 PostgreSQL 제약이 null 검토 사유를 거부해 기존 GENERAL_UNCERTAINTY 사유를 유지하고 CONFLICT 상태로 확정 비양립을 구분했다.
일반 SINGLE 불확실성은 비투영 검토이며 앞선 정상 항목의 소급 보류 근거가 아니다. 구 인물 단건 API는 읽기 전용 참조를 지원하지 않는다.

기존 C02 frozen-comparison claim 불일치로 전체 worker 연결은 미완료다. 새 긴 문서·세 순서의 실제 추출/비교와 현재 Java 격리 저장/API 연결은 작업 4에 남았다.
다음: 독립 Sol 검토 후 고정 원문·기대값으로 실행하며 첫 실패와 모든 실제 요청/응답 조건을 보존한다. PR·배포·복원 SHA 보완은 별도 지시를 따른다.

후속 현재/과거 변경은 원본 재생 RED·보호 3개 GREEN, 현재 미정 상태 보완은 원본 재생 RED·고정 응답 보호 8개 GREEN이다. 명시적 일반 규칙/예외 보완은 6 RED→46 GREEN, 관련 집중 검증 471 통과·2 제외(Java 실제 root 이동 자료 없음)다. 내부 근거 선택과 기존 보호 경계의 오프라인 검증이며 모델의 의미 효과를 증명하지 않는다. 정적 prompt namespace를 갱신했고 같은 Job checkpoint는 기존 invalidate 후 fresh analyze로 재검증한다. 과거 실제 짧은 비교·rare 결과는 후속 보완의 의미 PASS로 사용하지 않는다.
직접 현재 사실 보완은 원 semantic RED 1건을 변경 전후 그대로 보존하고, 고정 응답 계약 12개는 변경 전부터 통과했다. 변경 후 관련 458 통과·0 실패·0 제외이며 새 native·HTTP/DB 검증은 미실행이다.

후속 C02 claim 연결은 `supportsFrozenComparisonEvidence=true`와 ordered 응답 v1 검증을 추가했다. 집중 71 통과, 전체 2,581 통과·45 제외이며 과거 수치와 C02 미완료 기록은 당시 상태로 보존했다. 재개 checkpoint의 좁은 E→C 실제 HTTP claim·완료와 회복 근거 전달을 확인했다(새 API 비교 2회·정확한 기존 응답 재사용 1회). cold extraction·전체 순서·운영 반영은 미검증이며 상세의 2026-10-14 범위를 따른다.
