# v0007 — 충돌 판정과 설정한 추론 강도 전달

2026-10-09 · 적용: 작업 디렉터리, main·운영 미적용 · 이전: [v0006](v0006.md)

## 무엇을 바꿨나

- 값 차이나 새 문서의 정정 선언은 검토한다. 자동 UPDATE는 명시적인 변화 과정과 전후 상태를 요구한다.
- 표현 차이·양립 가능한 보완·명시적 제한 예외는 기존 의미를 보존하며, 같은 문서의 충돌 후보는 모두 검토하도록 기존 단건·묶음 비교를 안내한다.
- 공통 client가 GPT-6.1 Sol의 설정한 추론 강도를 누락하는 결함을 고쳐 실제 요청에 `max`를 전달한다. 운영 기본 모델·추론·상한은 유지했다.

## 검증과 한계

상태: **짧은 실제 비교와 코드 회귀 완료, 전체 의미 평가는 부분 완료**.
조건: 합성 사례 5종 × 단건/후보 1개 묶음, 비교 GPT-6.1 Sol·max·기본 속도, judge 없음.

동일 고정 입력의 짧은 정책 검사는 이전 prompt **5/10**, PR1 prompt **10/10**이다.
20회 모두 실제 요청과 공급자 응답의 max·기본 속도를 확인했다. 개별 operation과 값 보존의 제한된 검사이며 F1·전체 결정 정확도가 아니다.
앞선 20회의 설정 표기는 max였으나 실제는 medium이었다. 원본과 정정 근거를 보존했고 요구한 max 결과로 사용하지 않는다.
