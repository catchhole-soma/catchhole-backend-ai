# v0021 — 세계관 비교 크기를 Worker 토큰 기준으로 검사

2026-10-24 · 적용: 작업 브랜치 (배포 미확인)

## 무엇을 바꿨나

- Java 내부 JSON의 30,000자 제한을 제거하고 Worker의 최종 입력·예상 출력 토큰 검사로 일원화했다.
- 최초·형식 재시도·복구 요청의 입력 초과는 원본 경로·값을 보존한 검토 보류로 완료하고 다음 묶음을 계속한다.
- 후보 수·출처·문맥 정합성 검증은 유지하고, 보류 사유를 누적 참고에 남겨 의미 충돌로 오인하지 않게 했다.
