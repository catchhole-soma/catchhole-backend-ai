# v0010 — 질문 요구·같은 사건·실제 근거를 보존하는 챗봇

2026-10-15 · 적용: `feat/gh-241-chat-context`, 기능 기본 OFF · 로컬 회귀·실제 소규모 확인 완료

## 무엇을 바꿨나

- 질문의 요구를 독립된 부분으로 보존하고 같은 사건의 자료로 답한다. 지원 구절이 실제로 있는 원본 근거에 연결하며 추가 검색에서도 기존에 답한 부분을 보존한다.
- 대상 이름과 세계관 분류를 분리하고 공통 조회 경로를 사용한다. 조건 결과는 확인한 대상만 목록에 두고 미확인은 요약한다. 검색 순위·인접 문맥·새 벡터 후보 배분을 보완했다.
- 출력 잘림·schema/계약 오류의 제한된 재시도와 실패 사용량 정산을 연결했다. 해석/답변 출력 상한과 Java 예약 예산을 함께 조정했다. Luna·medium과 원문 문맥 6,000토큰은 유지한다.

## 평가

상태: 제품 보완·회귀와 실제 Luna 재검증을 마쳤다. 최종3건 중 부분 답변1건이 남으며 정식 품질 평가는 미측정이다.

| 검증 | 결과 |
| --- | --- |
| 최종 Python 전체 | 2,780 통과 / 54 skip / 기존 경고1 |
| 별도 격리 PostgreSQL 검색 | 26 통과 — 전체와 합산하지 않음 |
| 이번 Java 실행/계약 / bootJar | 21 통과 / 빌드 성공 |
| 전체 개발 중 Luna 확인 | 13건 실행 성공, ANSWER 10·명확화1·근거 부족2 |
| 최종 코드의 실제 재검증 | 3건 실행 성공·ANSWER 3; 원문 coverage COMPLETE 2 / PARTIAL 1 |
| 정식 의미 정확도·실비·지연 분포 | — 미측정 |

실행 성공·ANSWER 수·coverage는 의미 정답률이 아니다. 중간10건과 최종3건을 분리하고 과거 실패·사용량·실행 조건을 상세에 보존했다.
확인: 원문 대조에서 사건 시점과 인용 연결, 사건 전후 구분, 근거 없는 인과의 보류를 확인했다. 단일 소규모 확인을 일반 정확도로 확장하지 않는다.
한계: 관련 장면을 답변 입력에 전달했어도 요청 대상과 연결하지 못한 부분 답변1건이 남았다. 모델의 의미 판단과 검색 회수율은 추가 평가가 필요하다.
다음: #242에서 고정 질문·판정 기준으로 품질/비용/지연을 평가한다. #247과 OPT-09/18/19 보류는 유지한다.
운영: 이번 기록은 로컬 검증이며 운영 배포·기능 활성화·추가 백필 결과를 포함하지 않는다.
