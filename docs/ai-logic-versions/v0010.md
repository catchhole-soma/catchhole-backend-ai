## 무엇을 바꿨나

- 최근 대화로 지칭을 해석하되 매 질문마다 현재 RDB·직접 근거·원문을 다시 읽는다. 오래된 대화를 먼저 줄여 최신 자료를 보존한다.
- 유형과 실제 항목 경로를 먼저 확인하고 필터 후 이력을 조회한다. 새 focus 결과를 초기 2페이지/LLM 선택 10행으로 자르지 않는다. 현재값 한 조건에 맞는 인물 목록도 지원한다.
- 각 능력의 과정 질문은 모든 요청 항목을 답변 또는 미확인으로 표시한다. 검색 뒤 최종 근거 재검증 예산을 남기고, 내부 참조 대신 근거 번호·한국어 설명을 표시한다.
- 분류/근거 생성은 v3, 실제 항목 선택은 v1, 구형 계획의 행 선택은 v3다. 분석 Worker 모델·로직은 변경하지 않았다.

## 평가

상태: 조회·표시 구현과 합성 계약/회귀 검증 완료. 실제 모델 의미 품질 미측정.
조건: 합성 질문·고정 출력, 격리 DB/실제 Spring 조회, 별도 브라우저 회귀. 이번 보완은 provider/embedding/judge API key 미사용.
