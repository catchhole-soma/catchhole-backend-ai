# v0010 — 작품 전체 조회·의미 조건·항목별 원문 답변

2026-10-15 · 적용: `feat/gh-241-chat-context`, 기본 OFF · 로컬 커밋/미push

## 무엇을 바꿨나

- 질문의 대상·조건·답변 목적을 분리한다. 등록 인물 수, 세계관 분류 목록, 현재 서술형 조건을 조회하고 자료 없음·판단 보류를 확인 수와 구분한다.
- 소개는 근거 있는 자연어로, 보유 개수는 희망/계획과 구분해 답한다. 이력은 사건별로 세며, 생성 도중 현재 설정이 바뀌면 구값 답변을 보류한다.
- 같은 설정의 현재값·이력을 묶고 시점·과정을 각각 확인한다. 여러 항목의 검색 근거와 인접 문맥을 함께 배분하고 계획을 실제 획득 완료로 세지 않는다.
- 이력에 원문을 붙이는 요청을 원인 해석과 구분한다. 정상 부분 답변을 거부하던 검증을 고치고, 추가 근거는 행별로 병합하며 원문 미확인 기록도 보존한다.
- 챗봇을 Luna·medium으로 맞추고 원문 문맥을 6,000토큰으로 늘렸다. 겹침 계산과 예약 예산을 맞추며 제외 이유를 계측한다. 검색 범위·미확인은 본문으로 설명한다.

## 평가

상태: Luna 설정·문맥 예산·근거 진단 및 합성 회귀 완료. 최신 모델의 실제 의미 정확도·비용·지연 평가는 남아 있다.
