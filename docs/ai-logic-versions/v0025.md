# v0025 — 인용 원문 복원과 현재값·근거 분리

2026-10-28 · [Java #304](https://github.com/catchhole-soma/catchhole-backend-java/issues/304)

과거 확정 인용의 큰따옴표 누락이 새 비교 전체를 막지 않도록 현재값과 근거 확인 상태를 구분한다.
제품 모델·추론 강도 설정은 유지하며 추가 LLM 호출은 없다.

- 큰따옴표 3종과 공백만 다른 인용은 유일한 원문 slice·Unicode offset으로 복원한다.
- 과거 source의 `UNAVAILABLE/QUOTE_NOT_FOUND`를 잘못된 현재값으로 해석하지 않고 근거가 부족하면 검토로 남긴다.
- 안전한 실패 원인·단계·관측 HTTP·추적 ID를 끝까지 운반하며 기존 격리·재시도 분류를 유지한다.

## 평가

| 검증 | 결과 |

자동 회귀는 합성 입력 검증이며 실제 모델 정확도나 운영 실패율의 개선을 뜻하지 않는다.
Python skip 130과 Java skip 236은 별도 DB·HTTP export 등 기존 선택 환경 미지정이다.
과거 알림 seed TRUNCATE deadlock은 이번에 재현되지 않았고 원인 해결로 주장하지 않는다.

## 남은 조치

Backend additive schema·진단 수신을 먼저 배포한 뒤 AI를 적용한다. 실제 배포·Discord 수신은 미검증이다.
PR 담당자는 별도 평가 승인 후 동일 FIXED 조건으로 품질을 비교한다. 운영 작업 자동 재실행은 없다.

코드 복원 SHA·프롬프트 v11·호환성·실행 시점과 한계는 [상세 기록](details/v0025.md)을 따른다.
