# v0015 — 기존 대용량 원고 검색 지원

2026-10-16 · 적용: 작업 브랜치, 운영 반영 전

## 무엇을 바꿨나

- 기존 원고가 신규 업로드 글자 수 제한을 넘어 백필이 멈추는 문제를 수정했다.
- 색인과 Java 검색 인용을 UTF-8 2,000,000 bytes 이하로 맞췄다.
- 실제 원문 변경과 읽기 크기 초과를 구분하고 기존 진행·벡터·예산을 유지한다.

## 평가

상태: 합성 회귀 완료, 실제 모델 품질·운영 반영 미측정.
조건: 합성 원문·저장소/provider 대역, 모델·judge API 미사용.
소요: 집중 회귀 5.90초, 전체 Python 17.41초.

| 검증 | 결과 |
| --- | --- |
| 관련 Python 회귀 | 121 통과, 신규 경계 7개 포함 |
| 전체 Python 회귀 | 3,988 통과 / 132 skip / 기존 warning 1 |
| Java 인용·업로드 경계 | 54 통과 / 선택 HTTP 1 skip, bootJar 성공 |
| 실제 답변 품질·recall·비용 | — 미측정 |

기존 원문의 한글·줄바꿈·emoji 위치와 hash, 800/100토큰 청크는 보존한다.
환경 의존 skip은 통과로 집계하지 않으며 새 유료 호출은 하지 않았다.
신규 업로드·수정 제한과 사용자 과금 정책은 변경하지 않는다.
다량 재시도 시 실행 한도와 캠페인 소진 상태를 혼동하는 기존 한계는 #247 후속으로 남긴다.
