## 평가 실행 — YYYY-MM-DD-NN

추가 실행은 이 절을 복사한다. 이전 결과는 보존한다.
기본 조건은 FIXED, 추출 Sol·주체 해소 Terra·비교 Sol, 제품 reasoning medium이다.
평가 모델은 정식 모델명으로 기록하고 실제 실행값이 기본값과 다르면 그 값을 적는다.

| 항목 | 기록 |
| --- | --- |
| 상태 / 담당자 | 완료 / 부분 완료 / 실패 / 미측정; GitHub ID |
| 실행 시각·시간대 / 근거 | Actions run URL·ID 또는 로컬 실행 ID; 미실행이면 해당 없음 |
| 평가 대상 코드 SHA / 채점기 SHA | 전체 SHA 각각; 변경 파일 없는 커밋에서 실행했는지 |
| 평가기·reportVersion / 비교 실행 | multi_stage_setting 또는 setting_extraction; 비교할 버전·실행 링크 |
| 입력 | dataset version·fixtureHash, 원문 snapshot 식별값/해시·비공개 보관 위치 |
| 대상·상태 | 회차, 시나리오·의존 시나리오 수, domains, mode, stateApplicationPolicy, characterSchemaHash |
| 제품 실행값 | 추출·주체 해소·비교 모델, reasoning, promptVersions, maxChunks·청킹·출력/재시도 제한 |
| 채점 실행값 | judge on/off·모델·reasoning·cache 버전, worldSettingNamePolicy |
| 재현 명령 / Actions 입력 | 비밀값을 제외한 실제 값 또는 접근 가능한 비공개 실행 기록 |

다단계 비율은 0~1 그대로 적는다. 미측정은 `—`, 판정 미완료는 `null`,
ORACLE의 1차 또는 제외 도메인은 `해당 없음`이다. 레거시 평가는 실제 지표명·분모로 교체한다.

| 도메인 | 1차 P / R / F1 | 1차 값 정확도 | 2차 처리 / 전체 결정 정확도 | 최종 상태 F1 | 미판정 수(1차 / 2차 / 최종) |
| --- | --- | --- | --- | --- | --- |
| 캐릭터 | — | — | — | — | — |
| 세계관 | — | — | — | — | — |

- 1차 정답·예측 수 / 2차 정답·실제 채점 수: 도메인별로 기록.
- 런타임 실패 / 상태 적용 오류 / 의존 회차 적용 오류 / 전이 미판정:
- 비교 가능한 동일 조건인가 / 달라진 조건:
- 결과 해석·회귀·채택 이유: 미측정·불완전한 실행을 성능 개선 근거로 쓰지 않는다.
- 미측정·실패·부분 완료 사유:
- 재평가 계획: 담당자, 시점/실행 조건, 평가할 범위.

## 복원·배포 확인

- 복원 기준과 다른 최종 main SHA가 있다면 위 표를 보완한다.
- 배포를 확인한 경우만 배포 SHA/run 링크·세 Worker 적용·재분석 여부를 적는다.
- 확인하지 않았으면 `미확인`으로 남긴다. PR 머지를 배포 완료로 표시하지 않는다.
