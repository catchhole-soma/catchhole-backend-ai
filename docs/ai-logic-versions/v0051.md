# v0051 — 기존 속성값과 이번 값의 불일치 판정

2026-11-08 · 사용자 판정 기준 정정

## 무엇을 바꿨나

- 기존 값 A와 이번 값 B의 불일치를 비교한다. 기존 기록이 별도로 “B가 아니다”라고 말할 필요는 없다.
- 비교할 기존 값이 없는 경우와 확인된 값이 다른 경우를 구분한다. 변화 검색의 미발견으로 이미 확인한 불일치를 없애지 않는다.
- 질문의 속성과 확인하려는 값을 분리한다. 직업만의 예외 문구 대신 최상위 판정 정의와 마지막 확인을 함께 정정했다. 오탈자는 Terra medium으로 맞추고 설정 JUDGE는 Luna high를 유지한다.

## 평가

상태: 구현·로컬 검증 완료. 운영 오탈자 medium은 확인했으며 새 판정 프롬프트 배포는 별도 확인이 필요하다.

| 검증 | 결과 |
| --- | --- |
| Luna high 최종 합성 사실 전제·정상 문장 | 오류7/7(확정6·의심1)·정상12/12, 기대 분류 집합19/19 충족 |
| Terra medium 질문 분리 | 변경 후1/1 |
| 전체 자동 테스트 | 5,720 통과·186 skip·기존 경고1 |
| Backend 설정 바인딩·claim | 56 통과·실패/skip 0 |

최초18개 합성 단문은 변경 전후 모두 통과했다. 후속19개는 엄격한 확정도 분류18/19가 두 차례 나왔다. 시점 불확실한 세 사례는 합성 변화 검색 후 확정 또는 의심을 허용하도록 평가 조건을 명시했으며 과거 실패를 보존한다. 최종 수치를 기존 실행과 동일 조건의 개선으로 주장하지 않는다.
웹 저장 근거의 비공개 표본 재생에서는 기존·1차 수정 검출0/1 → 최종 수정1/1(의심)을 확인했다. DB 행은 이전 export의 재구성본이므로 당시 웹 요청과 완전히 같지는 않다.
새 프롬프트의 전체 웹 검수 정확도와 오탈자 medium의 개선 효과는 미측정이다.
