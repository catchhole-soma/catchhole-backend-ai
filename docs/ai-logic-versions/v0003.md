# v0003 — 신규 캐릭터 그룹 비교

2026-09-11 · 적용: main · 이전: [v0002](v0002.md)

## 무엇을 바꿨나

- 구체적인 신규 인물의 설정도 바로 확정하지 않고 그룹 비교로 넘겨, 발생·해제·재발 순서가 현재값에 반영되도록 했다.
- 회차별 원 분석 Job이 후보 게시 후 신규 캐릭터 비교 Job에 작업을 인계하도록 했다.
- 같은 사건의 근거만 중복 제거하고, 반복 문구처럼 위치가 불명확한 근거는 임의로 합치지 않도록 했다.

캐릭터 batch 비교 프롬프트 버전은 `v3`에서 `v4`로 변경됐다.
