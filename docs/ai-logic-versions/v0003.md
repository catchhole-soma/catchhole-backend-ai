- 전후 동작: 구체적 신규 이름의 `SETTING`도 `PENDING`으로 게시하고, 회차별 원 Job은 후보 게시 후 그룹 비교를 Spring 숨김 Job에 인계한다. 신규 그룹은 빈 snapshot에서 기존 batch projector로 순차 비교한다.
- 근거 중복 제거는 회차·원문 버전과 유일하게 확인된 전체 evidence 위치가 같은 사건에만 적용한다. 반복 quote나 불명확한 위치는 임의의 첫 위치로 합치지 않는다.
- 기대 효과와 회귀: 발생→해제→재발 순서와 의존성을 보존하면서 기존 캐릭터 batch 비교·세계관 stage·Worker 슬롯 동시성은 유지한다.
