## 평가

상태: 부분 완료. HYBRID, `gpt-6-luna`/medium, 질문 실행 동시성 2.

후속은 별도: 기존 1발화 FAIL, 신규 1발화 실행 실패, 기본 2발화 모두 PASS.
현재값 대조는 이전 6 PASS에서 이번 5 PASS/1 FAIL이며, 이전 결과와 실패를 함께 보존한다.
새 질문과 기본 질문에는 동일 질문 baseline이 없으며 묶음을 합쳐 총정답률을 만들지 않는다.
단일 반복의 차이는 회귀 후보이며 실행 성공·인용 위치 일치를 의미 정확도로 보지 않는다.
남은 문제: 재탐색 때 근거 손실·최종 시점 오답, 인용 참조 검증, 불필요한 되묻기·도움말 누락.

서비스 실행은 60발화 중 59성공/1실패로 의미 점수와 별도다. 이전 환경 실패도 보존한다.
