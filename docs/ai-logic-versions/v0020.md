# v0020 — 같은 캐릭터 호출에서 관계 관찰 추출 실험

2026-10-26 · 현재 실험 v2 · 기본 OFF · main 미반영·미배포 · PR 미생성

기존 캐릭터 추출 품질을 유지하면서 같은 호출에서 관계도 근거를 얻는 실험이다.
v2는 두 인물·상호작용 요약·인용만 받고 관계 종류·방향·확실성·시점 분류를 제외한다.
이번에는 코드를 바꾸지 않고 기존/축소안을 각 3회 추가해, 이전 2회와 누적 5회를 비교했다.

## 실제 API 비교

바바리안 1~4화 FINAL Gold, FIXED/CHARACTER, 추출 Sol / 주체 Terra / 비교 Sol / medium.
judge도 Sol·medium이며 원문·답지·스키마·코드·추출 요청을 고정했다.

| 누적 각 5회 | 기존 | 축소안 v2 |
| --- | --- | --- |
| 1차 추출 F1 평균 | 79.85% | 76.79% |
| 가중치 재현율 평균 | 75.00% | 70.83% |
| 최종 상태 F1 평균 | 87.40% | 85.56% |
| 필수 항목 완전 일치 | 113/145 (77.93%) | 102/145 (70.34%) |

신규 3회만의 평균도 F1 81.18→77.36%, 가중치 R 75.69→70.83%, 상태 F1 88.43→85.10%다.
필수 장비 2개 항목은 각각 기존 3/5회·축소안 0/5회 추출됐다. 직업 3개 항목도
각각 5/5→3/5회였으며 실패한 두 실행은 다른 프로필 경로에 분류했다. 누락과 경로 오류를 구분한다.
145는 필수 29항목×5회다. 같은 네 회차의 반복이며, 일반화·통계적 품질 보존을 보장하지 않는다.

관찰은 신규 6/20개, 누적 11/39개가 인용 검증을 통과했다. 관계 의미 정확도와는 다르다.
신규 통과 중 인사만의 과추출 1개, 두 이름 모두 미상인 단발 전투 1개도 있어 프로필 연결·관계 판단이 남았다.
신규 6회 실행 실패·상태 적용 오류·의미 미판정 0. 추출 재시도 0. 문서만 갱신해 전체 테스트는 재실행하지 않았다.
