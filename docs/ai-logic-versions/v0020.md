## 무엇을 바꿨나

- 현재값 질문은 실제 등록 자료로 검증하고, 원문·사용자 정정만으로 현재값을 바꾸어 답하지 않는다.
- 후속 정정·다항목 계획·재시도 입력을 복구하고, 읽지 못한 원문 후보를 다시 탐색한다.
- 후보 4는 현재값/원문 비교의 근거를 분리하고, 요청 누락과 coverage 모순을 구분해 복구한다.

## 평가

상태: 부분 완료. 고정 20문항, HYBRID, `gpt-6-luna`/medium, 동시 실행 2.
