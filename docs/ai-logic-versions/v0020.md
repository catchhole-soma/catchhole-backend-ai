# v0020 — 같은 캐릭터 호출에서 관계 관찰 추출 실험

2026-10-24 · 기본 OFF · main 미반영·미배포 · PR 미생성

기존 캐릭터 추출 품질을 유지하면서 관계도에 쓸 근거를 추가 호출 없이 얻을 수 있는지 실험했다.
관찰은 기존 설정과 분리하고 두 인물·방향·불확실성·시점·원문 근거를 보존한다.
잘못된 관찰은 제외하되 정상 설정을 버리거나 관찰만을 위해 다시 호출하지 않는다.

## 실제 API 비교

바바리안 1~4화 FINAL Gold, FIXED/CHARACTER, 동일 입력·모델로 각 버전을 두 번 실행했다.
추출 Sol / 주체 Terra / 비교 Sol / medium, judge도 Sol·medium이다.

| 지표 | 기존 1회 / 2회 | 관계 추가 1회 / 2회 |
| --- | --- | --- |
| 1차 추출 F1 | 84.21% / 88.89% | 82.46% / 85.00% |
| 최종 상태 F1 | 88.29% / 88.70% | 85.93% / 87.78% |
| 생성 호출 수 | 15 / 15 | 15 / 15 |

두 실행 평균은 추출 F1 **86.55%→83.73%**, 최종 상태 F1 **88.49%→86.85%**다.
2화의 중요 직업 3건이 다른 설정 경로로 추출되는 차이가 반복됐다. 값 정확도와 일부 회차는 개선됐지만
기존 품질 보존은 입증되지 않았다. 반복 수가 적어 통계적 비열등성이나 차이의 원인을 단정하지 않는다.

관계는 두 실행 모두 가족9·적대 행동1건, 근거 검증 제외1건이었다. 친구 양성 표본은 부족하다.
별도 실제 API 합성 대조6개 중2개에서 불필요한 관찰 또는 근거 누락이 있었다.
런타임 실패·상태 적용 오류·의미 미판정은 모두0. 최종 테스트 **4,256 통과 /134 skip /기존 경고1개**.

**기본 OFF 유지.** 직업 경로·관계의 과추출/방향/근거를 보완하고 실제 친구 표본으로 다시 평가한다.
이번 단계는 실험 구현·품질 검증이며 관계 저장·자동 확정·화면 공개는 포함하지 않는다.
Actions와 같은 Gold를 썼지만 스키마는 기존 로컬 fixture이며 현재 운영 registry와 동일성은 미확인이다.
