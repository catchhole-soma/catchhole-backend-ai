기존 캐릭터 추출에 관계 관찰을 추가한 v1과, 책임을 줄인 v2를 실제 API로 비교했다.
v2는 종류·방향·확실성·시점 분류를 없애고 두 인물·상호작용 요약·원문 근거만 받는다.
가족 호칭만의 중복 관찰을 제외하도록 요청하며 기존 설정 후보와 시간 문맥은 유지한다.

## 축소안 v2의 실제 API 비교

바바리안 1~4화 FINAL Gold, FIXED/CHARACTER, 기존과 축소안을 새로 각각 두 번 실행했다.
추출 Sol / 주체 Terra / 비교 Sol / medium, judge도 Sol·medium이다.

| 지표 | 기존 A / B | 축소안 A / B |
| --- | --- | --- |
| 1차 추출 F1 | 73.87% / 81.82% | 65.38% / 86.49% |
| 최종 상태 F1 | 85.42% / 86.29% | 84.68% / 87.86% |
| 생성 호출 수 | 14 / 15 | 14 / 15 |

두 실행 평균은 추출 F1 **77.85%→75.94%**, 최종 상태 F1 **85.86%→86.27%**로 혼재했다.
직업3건의 분류 차이는 재현되지 않았지만 A는 인물 발견이 줄었고 B는 중요한 무기2건을 놓쳤다.
기준 자체도 같은 입력에서 4화 주인공 해소가 흔들렸다. 두 번으로 인과관계나 품질 보존을 단정하지 않는다.

관찰의 인용 검증은 A **4/12건**, B **1/7건**만 통과했다. 의미 정확도와는 별도 수치다.
개발용 합성8개 중7개는 기대에 부합했지만 친분 불명만 있는 사례의 과추출은 남았다.
네 평가의 실행 실패·상태 적용 오류·의미 미판정0. 테스트 **4,257 통과 /134 skip /기존 경고1개**.

**기본 OFF 유지.** 평균 개선으로 중요한 팩트 누락을 상쇄하지 않는다. 기존 캐릭터 발견·주체 해소를
먼저 안정화하고 실제 관계 표본을 검수한 뒤 재평가한다. 관계 저장·자동 확정·UI 공개는 포함하지 않는다.
현재 운영 S3 스키마와 로컬 평가 fixture의 동일성은 미확인이다. 이전 v1의 실행과 결과도 모두 보존했다.
