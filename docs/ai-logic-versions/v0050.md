# v0050 — 인물 설정 추출 Terra medium 전환

2026-11-08 · 사용자의 비용 절감 결정

## 무엇을 바꿨나

- 인물 추출 전용 모델 설정을 추가하고 운영 기본값을 `gpt-6.1-terra`로 낮췄다. 추론 강도는 기존 medium이다.
- 세계관 추출은 기존 Sol을 유지한다. 관계·비교·검수 모델과 추출 프롬프트는 바꾸지 않았다.
- 모델 호출과 사용량 예약·claim·관측 모델을 맞추고 명시적인 CLI override를 유지한다.

## 평가

상태: 구현 및 로컬 검증 완료, 운영 적용 확인 전. 이미 수행한 삼국지 5화 비교를 근거로 선택했으며 새 유료 호출은 없다.
공식 Gold 정확도가 아니라 56개 항목에 대한 1회 표본 점검이다.

| 모델 | 완전 / 부분 / 누락 | 5회 추출 비용 |
| --- | --- | --- |
| Sol medium | 50 / 3 / 3 | $0.632195 |
| Terra medium | 39 / 8 / 9 | $0.227711 |
| Terra high | 40 / 8 / 8 | $0.309361 |

선택한 medium은 이 표본에서 64.0% 저렴했으며 공통 누락을 제외한 추가 누락은 6개다.
4개 회차의 과거 컨텍스트는 부분 복원본이므로 운영 전체 품질로 일반화하지 않는다.
전체 테스트 5,721 통과·186 skip·기존 경고 1. 독립 코드 검토에서 수정이 필요한 결함은 없었다.
최종 DB 상태 F1·새 모델의 실제 운영 누락률은 미측정이다.
