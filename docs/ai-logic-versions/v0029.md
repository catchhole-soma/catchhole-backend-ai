baseline 실행 기록에서 찾은 결정적 결함을 고쳤다. `gpt-6-luna`를 모르는 토큰 추정기가 한글 입력을 3~4배로 세어
60발화 중 44발화에서 근거가 잘렸고(수정 후 0), 등록 이력 페이지 조회가 도구 예산을 다 써 원문 검색이 시작되지 않던
경로를 예약으로 막았다. 회차는 맞췄지만 세부가 빠진 PARTIAL에는 2라운드에서 인용 장면의 이웃을 먼저 읽는다.
최초/최후 질문은 계획 `ordering`(plan v12)으로 인물명 필수·대상 단어 절반 일치 청크를 회차 순서로 읽고,
2라운드 의미 검색을 3배 넓혀 가장 이른 후보를 먼저 고른다(answer v15 `searchOrdering`).

개선 4건은 입력 절단 제거·장면 확장 경로였고, 후퇴 4건 중 2건은 재실행에서 재현되지 않는 모델 변동, 1건은
정렬 검색 v1이 일반 단어의 초반 언급으로 관련 후보를 밀어낸 결함이었다(최종 build에서 수정, 보조 재실행으로 확인).

모델·라운드·근거/도구/입력 상한·Spring wire 계약은 유지했고 운영 배포·운영 DB·운영 모델 호출은 하지 않았다.
