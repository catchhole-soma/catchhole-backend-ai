# v0029 — 실제 검수 실행과 성공 검사 재개

설정·오탈자 검사를 실제 Java 검수 Job과 연결했다.
검사가 중단돼도 같은 입력의 성공 계획·정상 판정·성공 오탈자 구간은 다시 호출하지 않는다.
새 단서가 바꾼 질문만 새 revision으로 판단하고 다른 정상 결과는 유지한다.

두 검사는 독립 실행한다. 한쪽 실패나 질문 0개로 다른 검사를 취소하지 않는다.
원고 교체·파기·lease 만료는 늦은 게시를 차단하고 실제 사용량 정산은 보존한다.
실행 중 종료도 예약 응답·UNKNOWN·SETTLE 정리가 끝난 뒤 HTTP를 닫는다.
추출 Job·후보·자동 확정·철회는 만들지 않는다.

설정집은 한 권씩 검토를 저장하고 남은 구간만 재개한다.
전체 책 본문을 checkpoint에 복사하지 않으며 기존 게시 크기 상한을 유지한다.
선택적 벡터 검색은 기존 색인과 명시 예산을 확인한다.
원 호출의 질의·입력·색인 identity에 맞는 성공 영수증만 재사용한다.

실행은 기본 비활성이고 명시 예산과 전용 opt-in이 필요하다.
일반 추출·챗봇의 모델과 재시도 기본값은 유지한다.
실제 모델 평가는 승인된 자료·예산으로 운영 활성화 전에 별도로 수행한다.
작가 판단·추출 허가 #312, 화면/회차 등록 제한 #314는 별도다.
