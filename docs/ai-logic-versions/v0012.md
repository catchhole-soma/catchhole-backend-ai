# v0012 — 질문 요구·사건 근거·등록 정보 부재를 구분하는 챗봇

2026-10-15 · 적용: `feat/gh-241-chat-context`, 기능 기본 OFF · 답변 v10 표시 회귀 완료, 새 실제 모델 품질 미측정

## 무엇을 바꿨나

- 작품 질문 없는 인사·감사·도움말에는 고정 안내로 응답한다. 작품 질문이 섞이면 일반 조회를 유지한다.
- 등록 정보가 없을 때 허용된 질문은 같은 실행에서 원문을 보완한다. 이전 답의 부재·불확실성을 되물으면 다시 확인하며 사실의 부정으로 바꾸지 않는다.
- 최초 획득 조건과 계획 schema를 맞추고 안전한 재시도 지침·진단을 추가했다. 관련 맥락과 실제 요구 충족을 구분하며 답변 검증 소진 시 미검증 주장을 버리고 검색·유효한 부분 답변을 이어간다.
- 이전 질문 요구·동일 사건·지원 구절 연결·존댓말 개선과 조회/실행 예산을 유지한다. Luna·medium과 원문 문맥 6,000토큰도 유지한다.
- 답변 v10은 미확인 요구를 자연스러운 문장으로 설명하고 포괄적인 미검토 안내를 제거한다. 해결된 요구의 설명은 병합에서 제거하며 실제 자료 오류는 남긴다.
- 원문 결합 답변도 생성 후 현재 설정을 재검증하고 변경 충돌을 통신 오류와 구분한다. 마지막 조회 비용은 기존 도구 한도 안에 남긴다.
