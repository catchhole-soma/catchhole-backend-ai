# v0004 — 회차별 자동 확정과 연속 분석 안정성

2026-09-13 · 적용: GH180 PR · 이전: [v0003](v0003.md)

## 무엇을 바꿨나

- 한 회차의 정상 설정을 저장한 뒤 다음 회차가 최신 확정 설정과 미해결 참고를 구분해 읽는다.
- 개별 연결·비교 오류는 원인과 원문을 보존해 검토로 남기고 다른 후보와 다음 회차를 계속 처리한다.
- 잘못된 응답의 제한된 재시도·부분 복구와 일반 불확실성 검토를 추가했다. 계정·사용량·입력·저장 오류는 계속 중단한다.
- 최신 main과 #65를 통합했다. 동료의 평가·provider 진단 및 300초 읽기 제한을 유지한다.

이전 로컬 코드의 실제 21~40화는 20회차 모두 완료됐고 비교 실패 4개를 검토로 남겼다.
후속 41~50화도 10회차 모두 완료됐다. 후보 187개 중 169개 반영·12개 제외·6개 세계관 검토이며 최종 비교 실패는 0개다.
41~50화의 9개 회차 간 연결과 입력·기록 hash를 확인했다. 중간 검증 재시도 4묶음은 회복됐다.

최신 upstream 통합 코드는 오프라인 AI 테스트 1,861개와 실제 PostgreSQL·Spring/Python 연동 21개를 통과했다.
이 통합 검증은 합성 원문과 고정 응답이며 외부 LLM을 호출하지 않았다. 통합 뒤 실제 원고 재실행과 동일 조건 품질 평가는 미실시다.

주체 과병합과 과도한 검토 보류 가능성은 남아 있다. 일반 검토 추가가 정확도 문제를 해결했다는 뜻은 아니다.
안정성 담당은 GH180 작업자, 정답지 평가와 정확도 개선은 별도 담당 이슈로 이어간다.
기존 실제 실행의 모델은 Terra/Luna/Luna·none이며, 운영 기본 조합의 품질 평가와 구분한다.
