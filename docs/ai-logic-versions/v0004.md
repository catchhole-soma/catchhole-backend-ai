# v0004 — 순차 분석과 최신 AI 변경 통합

2026-09-11 · 적용: 로컬 작업 브랜치 · 이전: [v0002](v0002.md)

## 무엇을 바꿨나

- AI main과 #65의 캐릭터 상태 판단·세계관 분류 개선을 순차 분석 코드에 반영했다.
- 같은 설정의 여러 후보라도 범위 확인이 필요하면 각각 검토로 남기고, 다른 정상 설정은 함께 처리하도록 지침을 정리했다.
- 복구 비교가 원래 설정 위치를 지키도록 우선순위를 명확히 하고, 새 평가기에 실제 저장 결과의 자료형을 전달했다.
- 대상 연결의 후보별 실패는 원인과 함께 보류하고 정상 후보를 유지한다. 세계관 신뢰도도 유한한 0~1 원값을 허용한다.
- 범위 외의 대상·내용 불확실성도 일반 검토로 표현하고 원본을 보존한다. 자동 확정하지 않는다.

일반 검토 추가 후 AI 1,798개 테스트와 고정 응답 2회차의 실제 API·DB 검증이 통과했다.
앞선 연결 오류 주입의 고정 응답 20회차 검증도 보존한다. 정확도 측정 결과는 아니다.

로컬 모델은 기존 Terra/Luna/Luna·none을 유지한다.
일반 검토 추가 뒤의 실제 LLM 재실행은 아직 하지 않았다. 주체 과병합 품질 문제도 관찰했다.
다음: GH180 담당자는 새 연속 실행을 확인하고, 정확도 담당자는 같은 조건의 평가를 진행한다.
