# v0006 — 추론 설정·순간 상태 범위·세계관 의미 비교와 실패 격리

2026-10-05 시작 · 최근 수정·검증: 2026-10-07 · 이전: [v0005](v0005.md)

## 무엇을 바꿨나

- GPT-6에도 환경변수의 추론 강도를 전달하고, 없으면 medium을 사용한다. 순간 감각·장면 반응의 추출 범위를 조정했다.
- 같은 주체의 사실은 정리용 분류가 달라도 비교한다. 기존 대상·적용 조건·저장 경로는 검증한다.
- 정상 판단과 병합 출처를 보존하고 실패·의존 묶음만 한 번 재시도한다. 직접 검토와 자동 처리에 적용했다.
- 채점기도 같은 복구를 사용하며 EXCLUDE의 원본 분류, 병합 출처 전체, 명시적 최상위 경로를 보존한다.

## 3화 같은 입력의 수정 전·후 실측

| 항목 | 수정 전 | 최종 수정 후 |
| --- | ---: | ---: |
| 세계관 비교 실행 실패 | 6/16 | 0/16 |
| 전체 2차 완전 일치 | 25/30 (83.33%) | 27/30 (90.00%) |
| 최종 상태 F1 도메인 평균 | 94.31% | 92.66% |

| 세계관 2차 입력+출력 토큰 | 34,229 | 25,961 |

Gold17과 저장된 1차 후보·이전 상태를 고정하고 세계관 2차만 재실행했다. 추출·인물 결과는 유지했다.
비교는 gpt-6.1-sol·medium, judge는 gpt-5.6-sol·medium, 모두 store=false다.
양쪽 동일 최종 채점기이며 의미 미판정·상태 적용 오류는 0이다. 이전 채점 결과와 측정도 보존했다.
실행 안정성과 2차 일치는 개선됐지만, 정상 처리된 추가 항목과 통합 단위 차이로 최종 상태 F1은 하락했다.
분류·주체 연결, 통합 방식, 원문의 불확실성 보존은 추가 검토 대상이다. 점수를 맞추려고 Gold를 바꾸지 않았다.
시간은 각 1회 실측이며 캐시·응답 지연이 다르다. 전체 분석 속도나 다른 회차 성능으로 일반화하지 않는다.
AI 전체 2,112개 통과·PostgreSQL 환경 필요 14개 제외, Backend 관련 131개 통과. AGENTS를 함께 갱신했다.
직접 검토의 그룹 확정은 실패 처리 완료를 기다린다. 부분 확정 화면은 추가하지 않았다.
통합 작업은 [AI #72](https://github.com/catchhole-soma/catchhole-backend-ai/issues/72)와 [Backend #227](https://github.com/catchhole-soma/catchhole-backend-java/issues/227)에서 추적한다.
코드는 커밋했으며 PR·배포 검증을 진행한다. Backend의 실제 API 배포 성공을 확인한 뒤 AI Worker를 반영한다.
