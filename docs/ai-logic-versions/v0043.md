모델은 관계 의미·방향·소유 관계를 선택하고 Worker가 고정 인물 참조를 복원한다.

잘못된 그룹만 한 번 다시 생성하고 정상 그룹과 남은 실패를 함께 원자 저장한다.
최초16묶음+복구16요청 상한이며 추가 호출에도 기존 토큰 계량·과금 정책을 적용한다.
출력 여유를 계획해 기본 batch당최대24쌍으로 묶으며 단일쌍 관측은 나누지 않는다.
그룹 실패는 내부 HOLD로 숨기지 않고 관계 일부 미완료로 표시한다.
인물이 애초에 해소되지 않은 관측만 모델 호출 없이 내부 HOLD로 유지한다.

이전 회차에 실패한 인물 쌍은 후속 회차에서도 미완료로 남기고 다른 쌍은 진행한다.
재claim에도 저장된 실패 개수와 PARTIAL을 복원하며 모델을 다시 부르지 않는다.
Job 성공은 실행 완료이고 관계가 전부 성공했다는 뜻은 아니다.
권한·lease·quota·API·provider 오류와 출력 절단은 기존 실패 처리로 남는다.
쌍당512토큰은 계획값이며, 큰 단일쌍의 출력까지 보장하지 않는다.

새 capability를 명시한 서버 계약에만 적용하며 wire 버전1을 유지한다.
Java API/마이그레이션을 먼저 배포하고 AI Worker를 뒤에 배포해야 한다.
합성 검증으로 실제 의미 정확도나 운영 실패율 개선을 주장하지 않는다.
초기 heartbeat와 최신 main의 실패 진단을 함께 보존했다. 미배포이며 담당 Codex/리뷰어가 승인된 품질 평가를 이어간다.
