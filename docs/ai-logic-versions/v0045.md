# v0045 — 신규 회차 검수 개편: 1만 자 계획·DB 우선 판정·RAG 재사용

2026-11-02 · 적용: 작업 브랜치(미배포, Backend와 함께 배포)

## 무엇을 바꿨나

- 계획: 원고를 1만 자 기준 구간 수로 같은 길이로 나눠 줄바꿈 뒤에서 자르고(grid v4) 구간을 병렬로 보낸다. 앞뒤 1,000자 문맥은 읽기만 하고
  질문은 자기 구간에만 단다. 질문을 더 많이 만들고 "나·너·그"는 장면 문맥으로 판단한다. 조회 계획 칸은 없다.
- 판정: 질문 주체의 DB 현재값(이력·세계관 변경 이력 없음)과 앞뒤 300자로 먼저 판정하고, 판단할 수 없을 때만 자연어 검색 최대 3개·원고 범위를 요청한 뒤
  결론을 낸다. 충돌 의심이면 변화 검색 한 번 뒤 다시 결론. 질문당 최대 3회, 4개씩 동시.
- 근거 조회: 의미 검색만 쓰고 같은 실행 안의 같은 검색은 재사용한다. 지칭 해소·COVERAGE·기계 단서·설정집 직접 검토·키워드 검색·최종 확인을 뺐다.
- 모델·추론 강도·출력 상한을 역할별 설정(configuration v2)으로 뺐다. 31화 비교용 로컬 실험 harness를 추가했다.
- 접수 때 색인 채우기: 검수 실행이 판정 전에 그 작품의 빈 RAG 색인(앞 회차·현재 판 설정집)만 채운다. 설정집 조각도 검색 근거가 되며
  판정 프롬프트는 설정집으로 표시한다. 채우기가 실패하면 검색이 필요한 질문만 `VECTOR_INDEX_FILL_FAILED`로 남는다. 아래 평가는 이 변경 전 측정이다.
- 오류 리포트 가독성: 판정이 근거 문장을 0~3개 정확히 인용하고(`basis_quotes`, Worker가 조각·설정 값에서 확인), 작가가 읽는 사유에서 T1·E2·B83·영수증 같은 내부 참조·용어를
  "이번 원고·18화·저장된 설정"으로 바꾸거나 뺀다. 같은 v3 schema 안 추가이며 실제 모델로는 아직 재지 않았다.
- 판정 규칙 보완(2026-11-03): 충돌은 "직접 어긋나는 이전 문장"이 있을 때만이고 그 문장을 근거로 인용해야 한다. 근거 문장 없는 충돌은 Worker가
  문제없음으로 바꾸고 센다. 판정이 검색을 요청하면 Worker가 대상 문장과 앞뒤 원고로 검색 하나를 더 하고, 변화 검색 문장은 확인 내용+대상 문장이다.
  로컬 31화의 "못 찾음 = 충돌" 오탐 대응이며 실제 모델로는 아직 재지 않았다.
- 판정 작성 제목·설명(2026-11-03): 판정이 제목(`headline`, 예 "데스핀드와 키메라 울프의 정수 등급이 기존 설정과 달라요")과 원인→결과 두 문장 사유를 쓴다.
  Worker는 제목을 사유처럼 정제하고 못 쓰면 비워 둔다(화면이 대신 만든다). 실제 모델로는 아직 재지 않았다.
- 표기 실수 보정(2026-11-03): disagreements 오용·NO_CONFLICT의 틀린 basis·잘못 옮긴 대상 span·오탈자 구간 상태 불일치는
  질문이나 분기를 실패시키지 않고 Worker가 바로잡아 센다. 심은 오류 31화 로컬 실행에서 심은 충돌 5개 중 4개를 찾았다(Gold 측정 아님).

31화(7,408자): 계획 Terra medium 81질문(출력 16,570토큰, 186초, $0.095, 상한 미도달).
같은 81질문 판정 — Terra medium $1.65·294초, Luna medium $0.20·402초, Luna high $0.24·726초. 세 실행 모두 81/81 결정, 양식 실패 0.
Luna medium은 인물 추측·회상 대사 2개를 충돌로 잘못 짚었고, Luna high는 오탐 없이 대사 2개를 "추가 확인"으로 보류했다.
오탈자 low는 Terra 제안 3개가 모두 맞았고, Luna는 3개 중 2개가 적용하면 원고를 틀리게 만든다.
선택: 계획 Terra medium, 판정 Luna high, 오탈자 Terra low.

남은 문제: Gold가 없어 놓친 충돌은 모른다. Luna high는 7천 자에 12분이라 긴 회차는 실행 시간이 늘어난다.
Backend 변경 전에는 실행 Job에서 동작하지 않는다(claim projectionVersion 2·configuration v2 필요).
