# 관계 의미 B/C 비교 결과 (GH442)

이 파일은 기본 구현과 확장 실험의 실제 실행 후 채운다. 현재 코드 작업 중이며 운영 도입 판단이나 측정값은 아직 기록하지 않았다.

- 추적: [Java #442](https://github.com/catchhole-soma/catchhole-backend-java/issues/442)
- 실행·계약: [3단계 실행 안내](../relationship-semantics-experiment.md)
- 기본 비교: 합성 10사례/11질의의 Python 객체 경로와 RDF·SHACL·SPARQL 경로.
- 추가 비교: AFFECTION 종류 추가 및 방향별 ATTITUDE 질의.
- 단계별 SHA와 실제 실행 산출물의 hash·환경·시간·크기를 최종 보고서에 기록한다.
