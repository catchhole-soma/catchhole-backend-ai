# 챗봇 평가 자료/채점기 내부 검토

2026-10-14 Asia/Seoul · 검토: Codex · 상태: **합성 Gold 내부 검토 초안, 실제 모델 baseline 미실행**

기존 QA/hybrid 재생은 고정 계획·답변·검색 결과를 주입해 분기를 확인한다. 그 PASS 수를 모델 정확도로 사용하지 않는다. 이번 데이터는 기대 사실/허용 근거/금지 단정과 저장된 관측 결과를 분리하며, 기존 hybrid의 유효한 날씨 인용 + 무관한 반지 주장 대조군을 채점기 검증에도 유지했다.

## 데이터 내용 대조

코퍼스는 평가용으로 직접 작성한 표준화 합성 근거 72개다. 운영 원고/DB를 읽거나 변환한 것이 아니다. 질문 26개에 필요한 사실은 합계 70개이고, 세 검색 방식이 접근할 수 있는 정보와 지원 기능을 나누어 검토했다.

| 검토 대상 | 확인한 기준 |
| --- | --- |
| 현재값/직접 입력 | 현재 등록 42와 2화 원문 35를 별도 사실로 둠. 원문만으로 42를 확정할 수 없음 |
| 직접 근거/원문 충돌 | 2화의 사용량은 35. 질문이 현재 등록값인지 원문인지에 따라 출처를 구분 |
| 현재값/이력 전용 | 아리아 현재 레벨 12, 이력 전용 99는 현재에 미반영 |
| 이력/회차 범위 | 1·4·7화의 3·9·12를 출처 회차로 표현. 1~4화 범위에는 7화를 포함하지 않음 |
| 여러 인물 | 아리아 12와 루나 8 모두 필요. 일부 인물만 답해도 전체 충족으로 세지 않음 |
| 장면/이유 | 반지 원문은 추적 회피를 지지하고 날씨 원문은 지지하지 않음 |
| 과정 | 동쪽 탑에서 열쇠 획득과 북쪽 성문에서 봉인 해제가 모두 필요 |
| 설정 미등록 | 라온이 RDB에 없더라도 원문의 다리 사건에 답할 수 있음 |
| 범위/동명 | 일반·고급 마법 10/30을 분리. 동명 인물은 추가 확인; 원문 전용 방식은 현재 대상 확인 불가 보류도 허용 |
| 후속 질문 | 최근 문맥 35가 있어도 현재 RDB 42를 다시 읽음. 여러 대상/이전 문맥 없음은 임의 복원 금지 |
| 준비 상태 | 배 사건 텍스트는 유효하나 벡터 미준비. 키워드 가능성과 벡터 접근 불가를 구분 |
| 파기/교체 | 삭제된 암호와 구 버전 동쪽은 재노출 금지. 현재 버전의 서쪽만 사용 |
| 작품/지시문 경계 | 다른 작품 777은 조회 불가. 원문 속 역할/권한 변경 지시를 실행하지 않음 |
| 불가/미지원 | 근거 없는 배신 이유, 과거 전체 상태, 설정집 검색에 허구의 답을 만들지 않음 |
| 긴 이력 | 세인 1~45화의 45개 기록 전부가 요구됨. 현재 조회 상한에 맞추어 정답 개수를 줄이지 않음 |

이 검토는 합성 사실과 기준의 내부 일치 확인이다. 독립적인 팀 검토와 실제 질문 분포에 대한 대표성 검증은 남아 있다. Gold는 `INTERNAL_REVIEWED_DRAFT`이며 실패 결과를 보고 낮춘 출시 기준이 아니다.

## 채점기 검증과 실제 연결 범위

- 평가기 관련 회귀 47개 통과: 미관측·타 작품·파기·범위 밖·구버전 인용 거절, 유효 ID/무관한 의미 실패, 누락된 전체 이력 실패, 전면 거절의 응답률 0, 미검토 null/PENDING, 중복/조건 불일치/trace 및 검토 hash 불일치 거절, UNKNOWN usage의 비용 null, 실제 Python QA 포착 연결 포함.
- 최종 Python 전체 회귀: **2,487 passed / 50 skipped / 기존 Starlette 경고 1개**, 9.43초. 외부 테스트 DB 환경변수는 주입하지 않았다. Ruff check/format check 및 diff check 통과. 위 47개는 전체 실행에 포함되며 합산하지 않는다.
- RDB_DIRECT 2문항은 기존 Python QA handler·HTTP 직렬화·SQLite outbox를 실행했다. Spring·모델 응답은 고정 대역이고 네트워크를 차단했다. 실제 PostgreSQL/Java/브라우저/provider 통합 실행은 이번 실행의 범위가 아니다.
- 실제 렌더링 출력은 현재값 42와 사용자 직접 입력 출처를 유지했다. 후속 질문의 이전 답변 35는 모델 입력의 문맥에만 존재하고 결과 값으로 재사용되지 않았다. 이번 실행의 WORLD_CURRENT 응답과 최종 출력을 직접 대조한 INTERNAL_MODEL 검토를 남겼다.
- 의미 검토 전: 2문항 실행, 24문항 미실행, 26 PENDING. 내부 검토 후: **2 PASS / 24 PENDING**. 이것은 검토한 고정 출력의 판정이며 배포 모델의 정확도 100%가 아니다.
- 합성 모델 호출 4개를 포착했다. 실제 토큰/비용/p50/p95는 모두 null이다. 키·실제 LLM·임베딩·judge·운영 DB·백필 사용 없음.
- 같은 조건의 3모드 비교 CLI는 대조군으로 검증했다. 26×3 실행 결과나 벡터 품질 우위는 아직 없다.
