# 설정집 인물 입력 축소

관련 이슈: https://github.com/catchhole-soma/catchhole-backend-ai/issues/147

사용자가 승인한 작업은 설정집 관련 캐릭터 선택과 중복 제거, 별도 worktree 구현,
실패 7건의 전후 입력량 및 회귀 테스트다. 기존 조사와 사용자 지시에 따라 이 범위에서 진행한다.

## 선택한 방향

동결 입력 전체는 검증·해소·비교에 유지하고 1차 추출의 모델 입력만 투영한다.
이름/별칭 카탈로그는 모두 유지한다. 모든 비어 있지 않은 행이 `이름: level=12`처럼
명시적인 age/level/나이/레벨/stats 수치 셀로만 구성될 때 해당 이름·별칭·짧은 이름의
모든 후보를 선택한다. 동명 후보는 하나로 해소하지 않는다. 이름 뒤 자연어 문장이나
자유 속성값, 일반/집단 규칙이 섞이면 전체 상세를 유지한다. 이름 제목이나 관계 단어
목록만으로 행 전체의 주체 범위를 확정하지 않는다.
이는 결정적 입력 선택이며 모델의 의미상 인물 해소를 대신하지 않는다.

- 중복만 제거하는 방안은 전역 문서의 안전한 fallback이 된다.
- 관련 대상 선택 + 중복 제거가 사용자 요청이다. 전역 규칙에는 선택을 적용하지 않는다.
- 회차처럼 CURRENT 전체를 빼는 방안은 설정집의 기존 의미축/보호/시점 정보를 잃으므로 사용하지 않는다.

## 표현

`book_character_context` 하나에 전체 `catalog`와 선택 대상 `characters`, 원래 순서의
`unresolved_references`를 둔다. catalog의 K ref는 현재 prepare_semantic_current_context가
배정한 ref를 그대로 사용하고, characters는 ref로 연결한다. 이름/별칭은 catalog에서 한 번,
식별 인용은 상세에서 한 번, 현재 슬롯과 출처/보호/시점/확정 표식은 유지한다.
동일 STATUS key/value가 양쪽에 있으면 current_slots에 active_status 메타데이터를 결합한다.
값이 다르면 양쪽 값을 모두 남긴다. fact_value/value_json은 의미 중복을 추측해 삭제하지 않는다.

## 경계

BOOK이고 ordered+semantic 문맥이 모두 있을 때만 적용한다. legacy 직접 호출과 EPISODE,
world, 식별/비교 파이프라인, DTO/hash/lease, 64,000 상한과 schema는 그대로 유지한다.
재시도는 최초 투영 prompt에 기존 안전한 correction을 덧붙여 같은 guard로 계산한다.
원문 일부를 자르거나 슬롯을 자르는 상한 우회는 하지 않는다.

## 검증

- 실제 provider 경계에서 상세 선택과 중복 제거, 원문/metadata/schema 유지 확인.
- 별칭/부분 이름/동명, 숫자+이름 연대 오탐, 이름 없는 전역 문서, 명시 전역 문서.
- STATUS 보호값·현재 시점·값 불일치, 임시 인물, 보류 참고와 원 입력 불변.
- 재시도와 입력 guard, 기존 관련 회귀 및 전체 pytest.
- 운영에서 저장한 7건의 입력을 read-only 복원해 동일 tokenizer와 response schema로 측정.
  raw와 ceil(raw*1.1)+256을 함께 보고, 고정 입력 fingerprint와 기준 실패를 검증한다.
  실제 원문/고객 정보는 저장소 fixture에 넣지 않는다. 이후 사용자 승인으로 같은 동결 입력의 실모델 전후 비교를 수행하며, 입력량과 의미 품질을 구분한다.

## 독립 검토 후 보완

최초 원문 이름 검색은 이름 있는 문장과 시민 일반 규칙/간접 지칭이 섞인 문서에서
일부 인물을 누락했고, 복합 조사/한 글자 짧은 이름도 놓쳤다. 6개 재현 테스트의 실패를
확인하고 위 명시 행 범위로 선택을 제한했다. 이 결정은 선택 가능한 문서를 줄이지만
불확실한 문서의 현재값을 보존한다. BOOK 지시의 기존 필드명도 새 문맥 위치로 연결했다.

## 실제 모델 검증 후 보완

입력 중복 제거가 원문에 재등장한 현재 사실의 생략으로 이어지는 사례와,
직책 값에서 상위 제목의 소속·명시적 수식어가 빠지는 사례를 확인했다.
BOOK 지시에 두 종류의 정보 보존을 명시하고 cache v3로 분리했다.
초기 및 중간 실행을 보존하며 최종 수치·블라인드 정답·검증 범위는
`docs/ai-logic-versions/details/v0053.md`에 기록한다. 운영 저장/차감/배포는 수행하지 않는다.
